## 核心理念：素材不是论证

> 例子和结论之间，必须有一条由作者亲手铺出的逻辑道路。
> 大多数"有素材却没分"的作文，缺的从来不是例子，而是这条路上的一根箭头。

这个 Skill 以论证为中心，而不是以"素材堆砌"为中心。

- 差学生停在"摆素材"；
- 中等生会"亮观点"；
- 高分作文把"论证"这条路铺通了。

一个重要的自我修正：本 Skill 早期版本曾把"五句一段法 + 素材库 + 家国视野 + 结尾呼吁青年"当成一类文标准。这是错的，那套组合是二类文的切入分（约 45–48），不是一类。新高考真正看的是内容、表达、发展，思辨型文章可以一个素材都不用，照样是一类文。

## 看效果

### 它审题的样子

> 你：帮我审这道作文题：古语云"父母在，不远游"，其后半句"游必有方"常被忽略。熟语云"不听老人言，吃亏在眼前"，而后半句"尽信老人言，终生难向前"却鲜为人知。

<br>

> AI：
>
> 题眼（关键词之间的关系）：不是"孝道"，也不是"独立"，而是"常被忽略""鲜为人知"所描述的那个现象——为什么修正、平衡的后半句，在传播中会先被丢掉？
>
> 关键概念具体化：
>
> | 关键词 | 本题中的含义 | 常见误解 |
> |---|---|---|
> | 常被忽略 / 鲜为人知 | 主动或被动地只接受一半的传播现象 | 误解为"记性差" |
> | 后半句 | 起修正、平衡作用的那一半 | 误解为"更正确的答案" |
>
> 立意建议（3 选 1）
>
> 立意 1：读懂"后半句"，才是对传统的真正传承
> - 中心句：真正的传承，不是背下最响亮的箴言，而是把它失落的后半句找回来。
> - 分论点骨架（每个都写清"凭什么成立"）：
> 1. 前半句留下、后半句丢掉，凭什么：简洁有力的更易流传，修正性的不便记忆
> 2. 只剩一半的古语会变成教条，凭什么：抽掉"游必有方"，孝就成了禁锢
> 3. 找回后半句靠主动的"完整阅读"，凭什么：传统不是标准答案，而是在情境里把握的"度"

完整示例看 `examples/01-示例_审题全流程.md`。

### 它改作文的样子

> 学生：《回到失落的伊甸园》（题目：人终其一生都在学着"与自我相处"，有时要重视自己，有时要放下自我）
>
> AI：
>
> 总评：本文属议论类偏题（42/60）。语言有质地、概念用得准，是一篇"写得漂亮却没答在点上"的文章：它用"回到伊甸园"把题目绕开了。
>
> 审题与评价标准（透明化）：
> - 材料在问什么：关键词是"学"与"相处"，问的是何时该重视、何时该放下、两者怎么共存。
> - 本文的扣题定位：材料问"怎么相处"，文章答"真正的乐园在前理性的浑然里"。关键词齐全，却把"相处"写成了"逃离"。判定：偏题。
>
> 分段点评（批注式，完整展示原文）：
>
> | 原文 | 批注 |
> |---|---|
> | 人终其一生，都在这两种痛苦中摇摆…… | 这句已摸到核心矛盾（重视↔放下），但你的处理是"两者都是痛苦"，等于取消了"相处"的可能。 |
>
> 评分：42 / 60（偏题封顶）
> - 内容 12/20 ｜ 表达 17/20 ｜ 发展等级 13/20（发展等级不能救偏题）
>
> 修改建议：把"逃离"改成"相处"——补一步判断标准（何时重视、何时放下），结尾把"回到伊甸园"翻转成"带着自我入世"。

不是笼统评语。先判扣题，再落到段、句、改成什么样。

### 它写的范文长什么样

> 无用的时间，有用的远方
>
> 我们习惯用"有没有用"给一切定价：读书要读能提分的，做事要做有回报的，连闲下来，也要问一句"这有什么用"。可"有用"与"无用"从来不是两样东西，它们只是同一样东西，在两个时间刻度上的名字。
>
> 崇尚"有用"，并不浅薄。它是文明得以运转的务实底色。但任何尺子，一旦成了唯一的尺子，就会反过来裁剪世界。
>
> 屠呦呦翻检东晋葛洪《肘后备急方》，读到"青蒿一握，以水二升渍，绞取汁"，从中得到低温提取的灵感。如果当年有人以"有用"为标准，把这类看似荒诞的旧方一并清掉，那么青蒿素也就失去了它最初的线索。

说人话 · 箭头外显 · 有"限定/反驳" · 不强行升华，真老师的范文，该长什么样就长什么样。

## 它能做什么

### 基础 5 模式 · 作文训练的全流程

| | 一句触发 | 它会做什么 |
|---|---|---|
| **M1 审题** | "帮我审这道题" | 三叩审题法：拆材料 → 找**题眼** → 具体化概念 → 给 3 个立意 |
| **M2 立意打磨** | "我想写 X 行不行" | 判断是否**另起炉灶** + 评估 + 优化建议 + 替代立意 |
| **M3 列提纲** | "给我列个提纲" | **论证段落闭环** + 每个分论点写清"凭什么成立" |
| **M4 写范文** | "写一篇范文我看看" | 850–1000 字范文 + 结构透视（标出箭头与限定） |
| **M5 批改评分** | "帮我改作文" | 60 制打分（内容/表达/发展）+ 分段评语 + 3 条可执行建议 |

### 进阶 4 模式

| | 一句触发 | 它会做什么 |
|---|---|---|
| **M6 整本批改** | "月考作文都发给你" | 逐篇简评 + 纵向进步分析 + 共性问题 + 训练建议 |
| **M7 话题定位** | "关于 XX 话题怎么写" | 匹配母题 + 三境七论视角 + 立意角度 + 可选素材 |
| **M8 限时训练** | "模拟高考 50 分钟" | 审题 8′ → 写作 35′ → 批改复盘 7′，全程提醒 |
| **M9 逻辑链审查** | "帮我看看逻辑" | 把文章还原成推理链，标出断在哪一环，说明补什么 |

### 开场先问三件事

第一次批改前，先问三个多选题（选"记住我的选择"就不再问）：

- 批改风格：平衡（默认）/ 偏严格 / 偏鼓励 / 自定义
- 输出格式：探讨式（默认，像老师当面聊）/ 报告式（分条列点）/ Word 文档
- 是否打分：需要（分数 + 三项维度）/ 不需要（只给评语建议）

若选了"Word 文档"，再追问文档视效：普通（默认）/ 美观 / 仅 Markdown / 纯文本。
生成时按内置的 python-docx 排版规范，并默认备好 Python 3.12 与 python-docx。

### 启动先自检更新

每次会话先比对本地 `VERSION` 与 GitHub 上的远程版本，有新版就提醒一句。

## 和别的作文 AI 不一样在哪

| 对比点 | 一般作文 AI | 本 Skill |
|---|---|---|
| **核心** | 堆素材、套模板 | **论证中心**：把素材做成论证 |
| **审题** | 只圈关键词 | 找**题眼**（关键词之间的关系）+ 三境七论 |
| **批改** | 笼统打分 + "加强文采" | 先定等级再找毛病 + 指出**哪根箭头断了** |
| **评分尺** | 把"素材多、有排比"当高分 | **素材不是硬指标**；思辨型零素材也能是一类 |
| **语言气质** | AI 味说教、论文腔 | **说人话**：判断密度，不是辞藻 |
| **反套路** | 教"万能开头/结尾" | 明确指出"五句一段＋素材堆砌＋呼吁青年"是二类切入分 |
| **能不能骗你** | 会编造"假古语" | 所有古语来自名句库，所有人物来自人物库，**编造即红线** |

## 工作原理

这个 Skill 不是在"堆词"。它做的是一位好老师会做的事：

审题地基 · 三立原则 + 题眼
- 立概念：关键概念必须具体化，结合材料限定到精准含义
- 立事实：现象必须展开分析（为什么 / 反映什么 / 影响什么）
- 立观点：所有观点必须证明，但"证明"不等于"举例"
- 找题眼：限制文章方向的，往往是关键词之间的关系

破题工具 · 三境七论
观境（关系论、认知论）→ 判境（困境论、价值论）→ 破境（方法论、边界论、发展论）。

论证技法 · 六大法
概念界定 · 偷换概念（泛化/神化/祛神化）· 归因法 · 推演法 · 反复法 · 辨析法。
外加思维链、隐含前提、反驳与修正、常见谬误清单。

段落骨架 · 论证段落闭环
观点 → 阐释 → 材料 → 分析 → 限定/反驳 → 回扣。每段都要让认识向前移动。

文风 · 说人话
新高考明确要求"说人话"。"不说人话"不是用词高级，而是把一句话拆成几个分句、用大词掩饰平庸。

## 来源与原创性

本 Skill 的上游是 [Weichenleeeee123/oh-my-chinese-teacher](https://github.com/Weichenleeeee123/oh-my-chinese-teacher)（MIT License）。本仓库不是它的简单改写，而是一次整体重构，方向与原作完全不同。

方向上的根本不同：

- 上游把「五句一段法 + 素材库 + 家国视野 + 结尾呼吁青年」当成一类文标准；
- 本项目明确把这套组合定为二类切入分（45–48），核心转向「论证中心」：例子与结论之间，那条由作者亲手铺出的逻辑道路。

原创性构成（按目录）：

- `references/`：基本为原创。`05`–`09`（论证技法、体裁创新、评价平衡性、逻辑链审查、docx 输出）为全新文件；`01`–`04` 亦大幅重写，与上游文字重合约一成到三成。扣题闸门、新高考 60 制评分尺、评价平衡性、体裁适配、逻辑链审查、docx 组件库等，均为本项目新作。
- `resources/`：`02-名句素材库.md`、`03-话题原型库.md` 主要沿用上游整理（致敬其工作）；`01-人物素材库.md` 经大幅增补改写；`04-校准数据.md`、`05-用户偏好.md`、`06-人与自我素材精编.md` 为本项目新增（06 由作者与一线语文老师共同整理，著作权保留）。
- `examples/`：三份示例在保留部分骨架的基础上重写。
