## 核心理念：素材不是论证

> 例子和结论之间，必须有一条由作者亲手铺出的逻辑道路。
> 大多数"有素材却没分"的作文，缺的从来不是例子，而是这条路上的一根箭头。

这个 Skill 以论证为中心，而不是以"素材堆砌"为中心。

- 差学生停在"摆素材"；
- 中等生会"亮观点"；
- 高分作文把"论证"这条路铺通了。

一个重要的自我修正：本 Skill 早期版本曾把"五句一段法 + 素材库 + 家国视野 + 结尾呼吁青年"当成一类文标准。这是错的，那套组合是二类文的切入分（约 45–48），不是一类。新高考真正看的是内容、表达、发展，思辨型文章可以一个素材都不用，照样是一类文。

## 看效果

### 它审题的样子

> 你：帮我审这道作文题："最重要"一词，常被我们用以确立事物的优先级，然而，对"最重要"的判断往往随立场、境遇而改变。还有人指出，当我们不断宣称某事物"最重要"时，正暴露了它在现实中的稀缺与脆弱。

<br>

> AI：
>
> 题眼（关键词之间的关系）：不是"最重要"三个字，而是 "流变"与"宣称"之间的张力，既然它会变，我们为什么还要喊？这就是全文的入口。
>
> 关键概念具体化：
>
> | 关键词 | 本题中的含义 | 常见误解 |
> |---|---|---|
> | 最重要 | 优先级最高者 | 误解为"很重要""所有关键事物" |
> | 宣称 | 用语言反复强调 | 忽略其"反复"的行为特征 |
>
> 立意建议（3 选 1）
>
> 立意 1：执一而应万，在流变中守护永恒
> - 中心句：真正的智慧，不在于找到永恒不变的答案，而在于流变中锚定价值、稀缺中用行动守护。
> - 分论点骨架（每个都写清"凭什么成立"）：
> 1. 流变是需求的动态适配，凭什么：需求本身是动态的，优先级只是需求的映射
> 2. 反复宣称暴露稀缺，凭什么：语言是补偿机制，越缺什么越强调什么
> 3. 以行动代替强调，凭什么：行动是唯一能真正改变稀缺的手段

完整示例看 `examples/01-示例_审题全流程.md`。

### 它改作文的样子

> AI：
>
> 总评：本文属议论类二类下（44/60）。扣住了第一句材料，素材也对路，是一篇"结构完整、任务完成"的安全卷。遗憾的是，它恰好是典型的"二类切入"文章，每一段都在换素材说同一句话，认识没有向前移动。
>
> 主体段 1（立场不同，判断不同）：论点成立，素材扣题。遗憾的是，你写的是"观点 + 举例 + 举例 + 所以"，缺那根箭头，立场为什么会影响判断？你只把素材摆出来，没把素材做成论证。
>
> 评分：44 / 60（二类下）
> - 内容 14/20 ｜ 表达 16/20 ｜ 发展等级 14/20（四项均平平，这是上不了一类的根本原因）
>
> 修改建议：
> 1. 【主体段 1】把素材做成论证，补上那根箭头。
> 现在：`袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。`
> 改成：`他见过 1960 年代的饥荒，正因为他亲历过"吃饱"的稀缺，这个选项才被推到价值排序的最顶端。`
> 2. 【主体段 2】补材料第二句，并让段落递进。
> 3. 【主体段 3 + 结尾】删口号，换成一个具体的"怎么办"。

不是笼统评语。具体到段、具体到句、具体到改成什么样。

### 它写的范文长什么样

> 执一而应万：在流变中守护永恒
>
> "最重要"一词，常被我们用以确立事物的优先级。可细看之下，这看似坚定的判断，却如流水般随立场与境遇变迁；而更耐人寻味的是，我们越是反复宣称某事物"最重要"，越像是暴露了它的稀缺与脆弱。既然它本会变，我们为何还要喊？这一问，正是全文的入口。
>
> "最重要"随立场境遇而变，自有其合理性。人的需求本身就是动态的，所谓优先级，不过是需求的映射。苏轼在乌台诗案前，把"致君尧舜"置于人生首位；贬谪黄州之后，却唱出"一蓑烟雨任平生"。这不是原则的崩塌，而是坐标的位移，正因为他的处境从庙堂跌入江湖，他的价值排序才必然重排。
>
> ……

说人话 · 箭头外显 · 有"限定/反驳" · 不强行升华，真老师的范文，该长什么样就长什么样。

## 它能做什么

### 基础 5 模式 · 作文训练的全流程

| | 一句触发 | 它会做什么 |
|---|---|---|
| **M1 审题** | "帮我审这道题" | 三叩审题法：拆材料 → 找**题眼** → 具体化概念 → 给 3 个立意 |
| **M2 立意打磨** | "我想写 X 行不行" | 判断是否**另起炉灶** + 评估 + 优化建议 + 替代立意 |
| **M3 列提纲** | "给我列个提纲" | **论证段落闭环** + 每个分论点写清"凭什么成立" |
| **M4 写范文** | "写一篇范文我看看" | 850–1000 字范文 + 结构透视（标出箭头与限定） |
| **M5 批改评分** | "帮我改作文" | 60 制打分（内容/表达/发展）+ 分段评语 + 3 条可执行建议 |

### 进阶 4 模式

| | 一句触发 | 它会做什么 |
|---|---|---|
| **M6 整本批改** | "月考作文都发给你" | 逐篇简评 + 纵向进步分析 + 共性问题 + 训练建议 |
| **M7 话题定位** | "关于 XX 话题怎么写" | 匹配母题 + 三境七论视角 + 立意角度 + 可选素材 |
| **M8 限时训练** | "模拟高考 50 分钟" | 审题 8′ → 写作 35′ → 批改复盘 7′，全程提醒 |
| **M9 逻辑链审查** | "帮我看看逻辑" | 把文章还原成推理链，标出断在哪一环，说明补什么 |

### 开场先问三件事

第一次批改前，先问三个多选题（选"记住我的选择"就不再问）：

- 批改风格：平衡（默认）/ 偏严格 / 偏鼓励 / 自定义
- 输出格式：探讨式（默认，像老师当面聊）/ 报告式（分条列点）/ Word 文档
- 是否打分：需要（分数 + 三项维度）/ 不需要（只给评语建议）

若选了"Word 文档"，再追问文档视效：普通（默认）/ 美观 / 仅 Markdown / 纯文本。
生成时按内置的 python-docx 排版规范，并默认备好 Python 3.12 与 python-docx。

### 启动先自检更新

每次会话先比对本地 `VERSION` 与 GitHub 上的远程版本，有新版就提醒一句。

| 对比点 | 一般作文 AI | 本 Skill |
|---|---|---|
| **核心** | 堆素材、套模板 | **论证中心**：把素材做成论证 |

| **批改** | 笼统打分 + "加强文采" | 先定等级再找毛病 + 指出**哪根箭头断了** |

| **反套路** | 教"万能开头/结尾" | 明确指出"五句一段＋素材堆砌＋呼吁青年"是二类切入分 |

## 工作原理

这个 Skill 不是在"堆词"。它做的是一位好老师会做的事：

审题地基 · 三立原则 + 题眼
- 立概念：关键概念必须具体化，结合材料限定到精准含义
- 立事实：现象必须展开分析（为什么 / 反映什么 / 影响什么）
- 立观点：所有观点必须证明，但"证明"不等于"举例"
- 找题眼：限制文章方向的，往往是关键词之间的关系

破题工具 · 三境七论
观境（关系论、认知论）→ 判境（困境论、价值论）→ 破境（方法论、边界论、发展论）。

论证技法 · 六大法
概念界定 · 偷换概念（泛化/神化/祛神化）· 归因法 · 推演法 · 反复法 · 辨析法。
外加思维链、隐含前提、反驳与修正、常见谬误清单。

段落骨架 · 论证段落闭环
观点 → 阐释 → 材料 → 分析 → 限定/反驳 → 回扣。每段都要让认识向前移动。

文风 · 说人话
新高考明确要求"说人话"。"不说人话"不是用词高级，而是把一句话拆成几个分句、用大词掩饰平庸。
