# 示例 · 批改全流程

> 一个完整的"学生交作文 → Skill 批改 → 学生追问 → Skill 复盘"的走查。
> 本文示范**现行**批改标准：先过**扣题闸门**，再按**报告式**输出（总评 / 审题与评价标准 / 批注式分段点评 / 语言与综合 / 参考评分 / 修改建议）。
> 文末另附**探讨式**的写法，供对照。
>
> 版权：学生作文来自作者语料库，著作权归作者保留，不在本仓库 MIT 许可范围内；姓名已隐去，仅作教学示例。

## 对话样本

### 学生输入

> 老师，帮我批改一下这篇。题目是：
>
> 人终其一生都在学着"与自我相处"：有时要重视自己，有时要放下自我。请结合材料，谈谈你的思考。
>
> ---
>
> **回到失落的伊甸园**
>
> "第六日，神用地上的尘土造人。"神取下亚当的肋骨，造了夏娃。
>
> 初生的伊甸园里，并没有"我"的概念。亚当看着夏娃，如同看着溪水中的倒影："这是我骨中的骨，肉中的肉。"此时的人，与自我相处的方式是"浑然"。正如婴儿分不清自身与世界的边界，亚当与夏娃处于一种前理性的混沌幸福中，没有物我之分，自然也就没有孤独。
>
> 直到那条蛇出现，带来了名为"理性"的苹果。蛇的诱惑不在于果实甜美，而在于那句咒语："你将如神一般，能知道善恶。"什么是知道善恶？就是学会了审视，学会了将"自我"从万物中剥离出来。
>
> 在咬下果肉的那一刻，理性的寒光照亮了伊甸园。亚当惊恐地发现，夏娃不再是自己的一部分，而是一个独立的"他者"。他开始意识到"我"的存在，更可怕的是，他开始在意"我在对方眼中是什么样子"。这是人类第一次"重视自我"的尝试，代价却是羞耻的诞生。他们急忙编织的无花果裙，便是人类文明史上的第一张面具。从此，人与自我的相处陷入了悖论：为了确立"自我"，我们必须将自己包装成一个特定的形象；而越是精心包装"前台"的形象，那个赤诚真实的"后台"自我便越发枯萎。我们并不是在认识自己，而是在按照"他者"的目光表演自己。
>
> 神将人逐出伊甸园，与其说是惩罚，不如说是某种必然。在这个名为"社会"的巨大剧场里，正如福柯所预言的那样，无形的规训无处不在。夏娃不再仅仅是夏娃，她是"妻子"，是"母亲"，是"大地的劳作者"。我们被迫在那一套套社会角色的紧身衣里，不断地"放下自我"，以换取群体的接纳；又在夜深人静时，因无法面对那个面目全非的灵魂而感到彻骨的虚无。
>
> 人终其一生，都在这两种痛苦中摇摆：要么在过度"重视自我"中陷入表演的焦虑，要么在过度"放下自我"中沦为社会的零件。夏娃站在荒原的风中，回望那个被天使把守的伊甸园。她多怀念，不用羞耻于将自己的全部展现给对方。在上帝苏醒之前，在理性的审判降临之前，那个无理性、无遮掩的状态，才是生命最蓬勃的原动力。只有在那里，自我才不需要被证明，也不需要被牺牲。
>
> 于是她起身，丢下手中的面具与工具，孤身一人，走向失落的伊甸园。

### Skill 输出（M5 · 批改评分）

```markdown
## 批改报告

### 总评
本文属议论类**偏题，42 / 60**。语言有质地、概念用得准，是一篇"写得漂亮却没答在点上"的文章：它用"回到伊甸园"把题目绕开了。

### 审题与评价标准

**材料在问什么**：关键词是"学"与"相处"。题目问的是"何时该重视、何时该放下、两者怎么共存"这门终身功课。

**评价标准**：新高考 60 制（内容 / 表达 / 发展）；先过扣题闸门（切合 / 基本切合 / 擦边 / 偏题 / 跑题），偏题封顶，发展等级的亮点不能顶破上限。

**本文的扣题定位**：材料问"怎么相处"，文章答"自我意识的诞生是一场悲剧，真正的乐园在前理性的浑然里"。关键词全用上了，但把"相处"写成了"逃离"。判定：**偏题**（碰到了核心，却把它替换成了一个更一般的命题）。

### 分段点评（批注式，完整展示原文）

| 原文 | 批注 |

| "第六日，神用地上的尘土造人。"神取下亚当的肋骨，造了夏娃。初生的伊甸园里，并没有"我"的概念。 | 起笔用典、画面感强，但第一段就把文章引向"创世神话"，而不是"与自我相处"。这是典型的**起笔宏大**：气势有了，题域却飘了。 |
| 此时的人，与自我相处的方式是"浑然"。【正如婴儿分不清自身与世界的边界】 | 【】处把"浑然"解释成"没有自我"。问题在于：题目问的是**有了自我之后**怎么相处，你却把答案放回了"没有自我"的起点。 |

### 语言与综合

**优点**：
1. 语言有质地，"理性的寒光""社会角色的紧身衣"这类表达有画面。
2. 概念用得住：戈夫曼的前台/后台、福柯的规训，落点都准，不是掉书袋。
3. 结构清楚，起承转合完整。

**遗憾的是**：
1. **扣题失守**：全篇在回答"自我意识为何是悲剧"，没有回答"如何与自我相处"。
2. **辩证缺席**：只写了两难，没有给出"何时该重视、何时该放下"的区分标准。
3. **结尾是逃离**：把"回到无理性状态"当作答案，既不可能，也不是题目要的功课。

### 参考评分

评分：**42 / 60（偏题封顶）**
- 内容 **12/20**：关键词齐全，但核心问题被替换，属偏题。
- 表达 **17/20**：语言与结构是本篇最强的部分。
- 发展等级 **13/20**：有创意、有个性，但**发展等级不能救偏题**。

### 三条具体修改建议

1. **【开头到"浑然"】把起点从"创世"挪到"课题"**。
   不要从"神造人"讲起，直接从题目给的处境切入：
   > "与自我相处"之所以是一门要学一辈子的功课，是因为它没有标准答案：太看重自己，容易活成一场表演；太看轻自己，又容易活成别人的零件。
   这样一句，就把"重视↔放下"的张力立起来了。

2. **【"两种痛苦"那段】把"两难"改成"如何共存"**。
   你现在停在了"摇摆"。补一步，给出**判断标准**：
   > 分寸不在"重视"与"放下"之间取中，而在**场合**：在需要承担责任时放下自我，在需要守住底线时重视自我。伊甸园的错，不在有了自我，而在误以为自我可以不要边界，也可以不要他者。
   这一步一补，文章就从"悲剧叙事"转向"相处之道"，扣题闸门就能过。

3. **【结尾】把"回到伊甸园"换成"带着自我入世"**。
   > 我们回不去伊甸园，也不必回去。真正的成熟，是带着那个会羞耻、会表演的自我，走进人群，再学会在人群里，把它安放好。
   同样的意象，从"逃离"翻转成"相处"，立意立刻回到题上。

> 一句总结：**这篇的问题不在文笔，在方向。** 把"逃离"改成"相处"，底子完全够一类。
```

## 学生的追问 · 为什么扣这么多分

### 学生输入

> 老师，我这篇语言不算差吧，怎么才 42 分？我感觉比班上很多篇写得好。

---

### Skill 输出（探讨式）

> 语言确实好，42 分里有一大半是语言和结构挣来的。但阅卷先看的不是语言，是**你有没有在回答题目**。
>
> 题目给的是一门"功课"：什么时候该重视自己，什么时候该放下，两者怎么共处。你写的是一则"神话"：自我一诞生就是悲剧，唯一的好是回到没有自我的从前。你把题目里的"相处"，换成了"逃离"。
>
> 打个比方：题目让你写"怎么和一位脾气古怪的室友长期同住"，你却写了一篇"人类为什么不该离开母腹"。文章很美，可它回答的是另一个问题。
>
> 你现在要练的不是文笔，是**扣题**：动笔前先写一句话，"题目到底在问什么，我这句话是不是只能在这道题上成立"。把这句话写出来，偏题就挡住了。
>
> 好消息是：你已经有能力把道理讲得漂亮。**方向一正，你的分数会跳。** 按上面三条改一版，发我看看。

## 附录 · 这个示例展示了什么

1. **扣题闸门先判**：判"偏题"要写出两句话（材料问什么 / 文章答什么），并落一个档、封顶，不许写区间。
2. **报告式结构**：总评 → 审题与评价标准 → 分段点评 → 语言与综合 → 参考评分 → 修改建议；审题模块透明化 AI 的尺度，可复核。
3. **批注式分段点评**：完整展示原文，旁批为主（左原文、右批注），局部问题用【】段内批。
4. **发展等级不救偏题**：本文表达 17/20，仍被扣题闸门封在 42。
5. **建议落到句**：三条建议都给了改后的示例句，并说明"为什么这样改就能过闸门"。

## 探讨式怎么写（对照）

如果学生偏好探讨式（默认），同一篇可以这样起，**不套固定开场**，从文章里最该说的那处切进去：

> 你这段"前台 / 后台"写得真好，可惜用错了地方。
>
> 题目让你谈"怎么相处"，你谈的是"为什么不该有自我"，你想说的是自我意识本身是场悲剧，可题目并不问这个。你碰了核心（重视与放下），却把它取消了。……
>
> （然后顺着原文往下讲，不摆小标题，不写"先说最要紧的一句 / 题目在问什么 / 这篇文章在答什么"这种固定三段式。）

## 这个示例没展示（但 Skill 应做的）

- 切合题意的高分篇：重点转到"如何再上一类"，而不是找毛病。
- 错别字 3 个以上：单独列出并说明扣分规则。
- 明显套作（网传万能开头）：指出并教他如何避免。
- 记叙文：说明"本 Skill 侧重议论文"，给基本反馈，不按议论文打分。
