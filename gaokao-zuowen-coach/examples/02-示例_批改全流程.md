# 示例 · 批改全流程

> 一个完整的"学生交作文 → Skill 批改 → 学生问为什么扣分 → Skill 复盘"的走查。
> 重点示范：先定等级再找毛病、"遗憾的是"句式、以及"素材不是论证"的讲法。

---

## 对话样本

### 学生输入

> 老师，我按"在流变中守护永恒"这个立意写了一篇，给我批改一下吧：
>
> ---
>
> 流变中的"最重要"
>
> 在我们的日常生活中，"最重要"这个词是经常被我们提起的。我们用它来确定事物的优先级。但是，"最重要"的判断会随着立场和境遇而改变，同时当人们反复强调某件事物"最重要"时，往往这件事物本身就是稀缺的。
>
> 每个人对"最重要"的理解都是不一样的。比如说，对于学生来说，学习最重要；对于工人来说，工作最重要；对于父母来说，孩子最重要。这就是我们所说的立场不同。袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。钱学森觉得报效祖国最重要，所以他回国参加建设。所以说，立场不同，对"最重要"的看法也不同。
>
> 另外，境遇也会影响我们对"最重要"的判断。苏轼本来觉得做官很重要，但是被贬之后他觉得自由和洒脱最重要，所以写了很多好文章。司马迁本来觉得出人头地最重要，但是受了宫刑之后觉得完成《史记》最重要。可见，境遇确实会改变我们的想法。
>
> 但是，有一些"最重要"是永恒的，比如说爱国、诚信、善良，这些都是永远最重要的。我们要记住这些，才不会在这个复杂的社会里迷失自己。作为高中生，我们要好好学习，天天向上，要把学习当成现阶段最重要的事情，这样才能考上好的大学，将来为国家做贡献。
>
> 总之，"最重要"虽然会变，但是我们要抓住那些永恒的东西，做好自己应该做的事情。这就是我对这道题的思考。

---

### Skill 输出（M5 · 批改评分）

```markdown
## 批改报告

### 总评
本文属议论类**二类下（44/60）**。扣住了第一句材料，素材（袁隆平、钱学森、苏轼、司马迁）也对路，是一篇"结构完整、任务完成"的安全卷。
**遗憾的是**，它恰好是典型的"二类切入"文章——**每一段都在换素材说同一句话**，认识没有向前移动；材料第二句"反复宣称暴露稀缺"几乎没碰；结尾是口号。它稳在二类，但上不了一类。

### 分段评语

**开头段**：材料复述基本到位，**但一件最重要的事没做——亮中心观点**。读者读完不知道你要证明什么。标题"流变中的'最重要'"也太弱，点到"流变"却没点到你的判断。

**主体段 1**（立场不同，判断不同）：
论点成立，素材扣题。**遗憾的是**：
1. 你写的是"观点 + 举例 + 举例 + 所以"，**缺那根箭头**——立场为什么会影响判断？袁隆平的选择凭什么能证明它？你只把素材**摆**出来，没把素材**做成论证**。
2. "学生 / 工人 / 父母"是空举例，无具体人物，删掉。
3. "袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子杂交水稻"——把活人压成了标签。

**主体段 2**（境遇改变判断）：
苏轼、司马迁很贴切。**遗憾的是**：
1. **与第一段没有递进**——两段都在说"X 会影响最重要的判断"，读者觉得你说了两遍。
2. **完全没碰材料第二句**——材料要素丢失一半。
3. "可见，境遇确实会改变我们的想法"——"确实""会"是虚词，没有力量。

**主体段 3**（有些最重要是永恒的）：
方向对（触到"守不变"）。**遗憾的是**：
1. "爱国、诚信、善良"直接抛出，无论证、无材料，是**空喊口号**。
2. "作为高中生……好好学习，天天向上，将来为国家做贡献"——**纯口号，减分项**。
3. 只说"要记住"，没说"怎么记住"，"怎么办"没落地。

### 结尾段评语
**这个结尾基本等于放弃**：复述观点 + 什么都没总结 + "这就是我的思考"。
新高考不强制"引一句 + 呼吁青年"，但结尾至少要**回扣 / 修正 / 开放**三者之一——你一个都没有。

### 语言与综合

**优点**：
1. 素材对路，扣得住第一层材料。
2. 没有错别字或逻辑硬伤。

**遗憾的是**：
1. **论证基本缺席**——四段里没有一处"凭什么"，全靠"所以说""可见"硬跳。
2. **句式单调**——全是陈述句，没有追问、假设、限定。
3. **空喊口号**——"好好学习，天天向上""将来为国家做贡献"在议论文里是减分项。
4. **没有辩证**——只说"会变"和"有永恒"，没解释二者**为什么能并存**。

### 评分：44 / 60

**等级**：二类下

**主要依据（新高考三项）**：
- 内容 **14/20**：扣住第一句、丢失第二句，立意平直缺辩证，有空口号
- 表达 **16/20**：结构完整、语言通顺，但句式单调、无节点词
- 发展等级 **14/20**：深刻 / 丰富 / 有文采 / 有创意，**四项均平平**——这是上不了一类的根本原因

### 三条具体修改建议

1. **【主体段 1】把素材做成论证——补上那根箭头。**
   现在：`袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。`
   改成：
   > 袁隆平的"最重要"不是凭空而来的。他见过 1960 年代的饥荒，**正因为他亲历过"吃饱"的稀缺，这个选项才被推到他价值排序的最顶端**——立场的背后，是切肤的境遇。
   （加粗处就是你缺的**箭头**：从"立场"到"判断"之间的机制。）

2. **【主体段 2】补材料第二句，并让段落递进。**
   第二段不要再重复"境遇会变"，而要推进到：
   > 更耐人寻味的是，我们越是反复宣称某事物"最重要"，越暴露它在现实中的稀缺。林觉民在起义前夜写给陈意映的绝笔信中反复倾诉"吾至爱汝"——**若这份爱早已安稳无虞，又怎会在纸上反复泣血？** 可见，反复宣称从不是坚固的证据，而是脆弱的自白。

3. **【主体段 3 + 结尾】删口号，换成一个具体的"怎么办"。**
   把"好好学习、为国家做贡献"整段删掉，改为：
   > 与其空喊"诚信最重要"，不如从一次不抄袭的作业开始；与其把"健康最重要"挂在嘴边，不如每天多走十分钟。真正的"最重要"，从不需要宣讲，它活在行动里。
   结尾用"修正式"收束：
   > "最重要"从来不是一个等着被找到的答案，而是一个正在被行动不断重排的坐标。
```

## 学生的追问 · 为什么扣这么多分

### 学生输入

> 老师，我感觉我写的还可以啊，怎么才 44 分？我的素材不都用对了吗？

---

### Skill 输出

```markdown
我理解你觉得"不差"。但换个角度：阅卷老师判断"好不好"，**不是看你用了什么素材，而是看你有没有把素材做成论证**。

### 类比一下

你这篇作文，**像一堆好食材没炒成一道菜**：
- 袁隆平、钱学森、苏轼、司马迁，都是上好的食材；
- 可你只是把它们**摆在盘子里**（一句话带过），没有**炒**（没有那根箭头）。

所以阅卷老师看到的是——"这学生知道考题要用袁隆平，但不知道**为什么**用。"

### 高分作文的关键不在素材，在"那根箭头"

同样用袁隆平：

**你的写法（说明式）**：
> 袁隆平觉得让大家吃饱饭最重要，所以他研究了一辈子的杂交水稻。

**一类文的写法（论证式）**：
> 他见过 1960 年代的饥荒。**正因为他亲历过"吃饱"的稀缺，这个选项才被推到价值排序的最顶端**——立场的背后，是切肤的境遇。

区别不在"有没有君不见"，而在**有没有那句"正因为……才……"**。前者只是复述，后者才建立了**因果箭头**。

### 分数对照表

| 你的动作 | 效果 |
|---|---|
| 引了材料、素材对路 | 内容分部分完成 ✓ |
| 没有箭头（"所以说""可见"硬跳） | 表达分丢失 ✗ |
| 空喊"好好学习"口号 | 内容分倒扣 ✗ |
| 结尾没回扣 / 没修正 | 表达分丢失 ✗ |

这就是 44 分的来源。**不是你素材不对，是你没把素材做成论证。**

### 好消息

你的**底子不差**——选得对素材、扣得住题眼、段落分清了，很多三类文做不到这些。

你现在要练的**不是换素材、不是背金句**，而是：
1. 每写完一个素材，问自己一句"**凭什么它能证明我的观点**"，把答案写出来；
2. 练"**让步/限定**"——承认对方在什么条件下成立；
3. 练"**把口号变成动作**"——主体、动作、代价写清楚。

按那三条建议改一版，发给我。
```

## 附录 · 这个示例展示了什么

1. 先总评定位（二类下），并说清为什么。
2. 先定等级、再找毛病，不拿清单逐条扣。
3. "遗憾的是"句式作为指出问题的标准起手。
4. 新高考三项打分（内容 / 表达 / 发展），发展等级"四项均平平"是上不了一类的关键。
5. 三条具体建议，每条指明段落 + 给出示例句。
6. 讲清"素材不是论证"，用"好食材没炒成菜"的类比。
7. 尊重学生情绪，先肯定底子，再给明确训练路径（练箭头，不换素材）。

## 这个示例没展示（但 Skill 应做的）

- 严重跑题：直接指出"基本脱题，建议重写"，不硬打分
- 错别字 3 个以上：单独列出并说明扣分规则
- 明显套作（网传万能开头）：指出并教他如何避免
- 记叙文：说明"本 Skill 侧重议论文"，给基本反馈，不按议论文打分
