# 示例 · 范文生成全流程

> 一个完整的"学生请求提纲 → Skill 给提纲 → 学生请求范文 → Skill 写范文 + 结构透视"的走查。
> 重点示范：提纲里每个分论点都要写清"凭什么成立"；范文要能看出"箭头"和"限定"在哪。

---

## 对话样本 · 第一轮 · 提纲生成

### 学生输入

> 老师，上面那道"最重要"的题，我选立意 1"执一而应万"，帮我列一份提纲吧。

---

### Skill 输出（M3 · 提纲生成）

```markdown
## 提纲：执一而应万——在流变中守护永恒

### 标题候选
1. 执一而应万：在流变中守护永恒 ⭐
2. 承认流变，锚定稀缺
3. 万变的"最重要"，不变的行动

### 开头段（约 130 字）
- **建立的问题**：既然"最重要"随境遇而变，我们为什么还要反复宣称它？"变"与"宣称"的矛盾，是本文入口。
- **中心观点**：真正的智慧，不是在流变之外找到永恒答案，而是**在流变中锚定价值，在稀缺中用行动守护**。

### 主体段 1：承认流变（观境 / 合理性）
- **观点句**："最重要"随立场境遇而变，是需求的动态适配，自有其合理性。
- **阐释**：人的需求本身是动态的，优先级只是需求的映射。
- **材料**：苏轼（乌台诗案后，把"保全生命与民生"置于"致君尧舜"之上）。
- **分析（箭头）**：**因为**他的处境从"庙堂"变成了"江湖"，**所以**他的价值排序必然重排——变的不是原则，是需求。
- **限定**：但流变不等于虚无——变化的是排序，不是"有所珍视"这件事本身。
- **回扣**：承认流变，是对人性复杂的尊重。

### 主体段 2：洞察悖论（判境 / 本质）
- **观点句**：反复宣称"最重要"，恰是其稀缺脆弱的反向证明。
- **阐释**：语言是补偿机制——越缺什么，越强调什么。
- **材料**：林觉民《与妻书》反复倾诉"吾至爱汝"。
- **分析（箭头）**：**若**这份爱早已安稳无虞，**又怎会**在纸上反复泣血？——反复本身泄漏了缺口。
- **限定**：当然，强调并非全是虚弱——但**当强调成为唯一动作时**，它就只是焦虑的回声。
- **回扣**：反复宣称不是坚固的证据，而是脆弱的自白。

### 主体段 3：行动守护（破境 / 怎么办）
- **观点句**：以"内核守一"应"表象万变"，以"行动填补"治愈"语言焦虑"。
- **阐释**："内核守一"指把价值锚定在自身行动上；"行动填补"指用实干替代口号。
- **材料**：袁隆平（从不说"吃饭最重要"，却用一辈子让中国人吃饱）。
- **分析（箭头）**：**正因为他**把"最重要"放进了稻田而非讲台，**所以**他的珍视不需要任何宣讲来证明。
- **具体动作**（方法论落地）：与其空喊"健康最重要"，不如每天多走十分钟；与其反复说"诚信最重要"，不如从一次不抄袭的作业开始。
- **回扣**：真正的"最重要"，活在行动里。

### 结尾（约 100 字）
- **修正式收束**："最重要"不是一个等着被找到的答案，而是一个正在被行动不断重排的坐标。

### 提纲小结

| 段 | 论证动作 | 那根"箭头" |
|---|---|---|
| 主体 1 | 承认流变 | 处境变 → 需求变 → 排序变 |
| 主体 2 | 洞察悖论 | 稀缺 → 补偿性强调 |
| 主体 3 | 行动守护 | 价值锚定行动 → 无需宣讲 |

### 下一步
- 按这份提纲自己写一版（推荐）；
- 或说"**按这份提纲写一篇范文**"。
```

## 对话样本 · 第二轮 · 范文写作

### 学生输入

> 老师，按这份提纲写一篇范文给我看看，我想参照一下。

---

### Skill 输出（M4 · 范文写作）

```markdown
## 范文

### 执一而应万：在流变中守护永恒

"最重要"一词，常被我们用以确立事物的优先级。可细看之下，这看似坚定的判断，却如流水般随立场与境遇变迁；而更耐人寻味的是，我们越是反复宣称某事物"最重要"，越像是暴露了它的稀缺与脆弱。**既然它本会变，我们为何还要喊？**——这一问，正是全文的入口。在我看来，真正的智慧不在于找到一个永恒不变的答案，而在于**在流变中锚定价值，在稀缺中用行动守护**。

"最重要"随立场境遇而变，自有其合理性。人的需求本身就是动态的，所谓优先级，不过是需求的映射。苏轼在乌台诗案前，把"致君尧舜"置于人生首位；贬谪黄州之后，却唱出"一蓑烟雨任平生"，将生命的保全与民生的关怀提到了更前。**这不是原则的崩塌，而是坐标的位移——正因为他的处境从庙堂跌入江湖，他的价值排序才必然重排。** 变的从来不是"有所珍视"这件事，而是"珍视什么"。承认这种流变，不是虚无，而是对人性复杂与现实多元的尊重。

然而，更值得追问的是：当我们不断宣称"某事物最重要"时，我们究竟在说什么？稀缺催生重视，脆弱倒逼强调——**我们高喊什么，往往恰恰因为缺少什么**。林觉民在起义前夜写给妻子的绝笔信中，一遍又一遍地倾诉"吾至爱汝"；若这份爱早已安稳无虞，又怎会在纸上反复泣血？这份反复本身，就是爱在国难当头时的脆弱自白。诚然，强调未必都是虚弱——父母反复叮嘱"注意身体"，其中自有牵挂；**但当强调成为唯一的动作时，它就只剩焦虑的回声。** 由此可见，反复宣称从来不是坚固的证据，而是脆弱的自白。

看清了流变与稀缺，青年的出路在哪里？答案或许在于：**以"内核守一"应对"表象万变"，以"行动填补"治愈"语言焦虑"。** 袁隆平从未在讲台上强调"吃饭最重要"，却用六十年躬耕稻田让中国人不再挨饿；**正因为他把"最重要"放进了稻田而不是讲台，他的珍视才不需要任何宣讲来证明。** 对我们而言，与其空喊"健康最重要"，不如从每天多走十分钟开始；与其反复说"诚信最重要"，不如从一次不抄袭的作业开始。价值从来不是喊出来的，它是在一次次具体的行动里，被一点点坐实的。

"最重要"从来不是一个等着被找到的答案，而是一个正在被行动不断重排的坐标。它会随境遇流动，也总在稀缺处发出焦虑的回声——但只要我们把脚踩在行动上，就不必害怕它的流动，也不必依赖它的响亮。愿我们都能在万变之中，守住那个不靠宣讲、只靠践行的内核。

---

（全文约 920 字）

## 结构透视

| 段 | 论证动作 | 关键"箭头" / 亮点 |
|---|---|---|
| 开头 | 建立问题 + 亮观点 | 用"既然它会变，为何还要喊"把两句话拧成一个问题 |
| 主体 1 | 承认流变 | **正因为处境变，所以排序变**——不是原则崩塌，是坐标位移 |
| 主体 2 | 洞察悖论 | **若爱安稳，怎会反复泣血**——从现象推出机制；有**限定**（强调未必都虚弱） |
| 主体 3 | 怎么办 | **正因为放进稻田而非讲台，才无需宣讲**——并落到具体动作 |
| 结尾 | 修正式收束 | 把"找答案"改成"重排坐标"，回扣开头 |

## 语言风格说明（供对照，不必照搬）

1. **说人话**：没有堆大词；"喊""坐实""踩在行动上"都是日常词。
2. **箭头外显**：全文三处"正因为……才……""若……又怎会……"，把逻辑写在了纸面上。
3. **限定/反驳**：主体 2 有"诚然，强调未必都是虚弱……但当强调成为唯一动作时"，这是**一类文的分水岭**。
4. **不强行升华**：结尾用"修正"收束，没有"愿我辈青年……"的空呼吁。

## 写作提醒

- **不要抄**：抄原文到考场 = 套作，直接判低分。
- 正确用法：**看懂骨架 → 理解箭头 → 用自己的话重写**。
- 建议先不看范文，按提纲自己写一版，写完再对照，才知道自己弱在哪。
```

## 附录 · 这个示例展示了什么

### 提纲阶段（M3）
1. 给 2–3 个标题候选，不一锤定音。
2. 每个分论点都写清"凭什么成立"（那根箭头），这是新版核心。
3. 用论证段落闭环（观点→阐释→材料→分析→限定→回扣），不是僵化的五句。
4. 推荐素材前先在 `resources/01` 查证。
5. 说清每段的论证动作。

### 范文阶段（M4）
6. 范文严格按提纲写，850–1000 字。
7. 附结构透视，标出箭头与限定。
8. 主动提醒"不要抄袭"，给出正确参考用法。
9. 不强行"君不见"排比，也不强行"吾辈青年"结尾，需要时才用。

## 这个示例没展示（但 Skill 应做的）

- 学生要"换个素材重写"：按同样骨架换素材。
- 学生说"这段看不懂"：拆成"观点→阐释→材料→分析→限定→回扣"逐句讲。
- 学生问"这篇范文多少分"：按批改标准自评（本篇约 53–55，一类下：论证清楚、有思辨、语言说人话）。
