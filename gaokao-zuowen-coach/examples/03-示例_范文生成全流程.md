# 示例 · 范文生成全流程

> 一个完整的“学生请求提纲 → Skill 给提纲 → 学生请求范文 → Skill 写范文 + 结构透视”的走查。
> 重点示范：提纲里每个分论点都写清“凭什么成立”；范文要能看出“箭头”和“限定”在哪。
>
> 版权：本题为公共考试材料；文末对照的年级范文来自作者语料库，著作权归原作者保留，此处仅引标题与思路作对比，不全文收录。

---

## 对话样本 · 第一轮 · 提纲生成

### 学生输入

> 老师，帮我审一下这道题，再给我列个提纲：
>
> 阅读下面的材料，根据要求写作。
>
> 明清之际一批思想家提出“经世致用”的主张，认为学问必须有益于解决社会问题；李白吟出“天生我材必有用”的千古名句。庄子却说“无用之用，方为大用”；有现代学者认为：“读一些无用的书，做一些无用的事，花一些无用的时间，都是为了在一切已知之外，保留一个超越自己的机会。”
>
> 对于“有用”与“无用”的内涵与关系，你有怎样的思考？请自定角度，自拟题目，写一篇议论文。不少于 700 字。

---

### Skill 输出（M1 简版 + M3 · 提纲生成）

```markdown
## 审题要点

- **核心概念**：“有用”与“无用”的**内涵与关系**（是一组关系型材料，不能只谈一边）。
- **题眼**：材料把“有用”（经世致用、天生我材）和“无用”（庄子、现代学者）并置，真正的入口是**二者如何转化**，而不是“哪个更重要”。
- **隐性限定**：现代学者那句已经给了钥匙，“在一切已知之外，保留一个超越自己的机会”。**“无用”的价值，在于它是通往“未知”的入口。**

## 提纲：无用的时间，有用的远方

### 标题候选
1. 无用的时间，有用的远方 ⭐
2. 无用之用，是留给时间的
3. 别把一切都算成账

### 开头段（约 130 字）
- **建立的问题**：我们习惯用“有没有用”给一切定价，可“有用”与“无用”从来不是两样东西，而是同一样东西在两个时间刻度上的名字。
- **中心观点**：**无用的价值，不在眼前，而在它替未来保留了可能性；给无用留一点时间，就是给超越自己留一条路。**

### 主体段 1：承认“有用”的正当性（观境 / 合理性）
- **观点句**：崇尚“有用”并非浅薄，它是文明得以运转的务实底色。
- **阐释**：一个社会若完全不问功用，知识就成了自娱；“经世致用”之所以被提出，正是为了纠正空谈。
- **材料**：明清实学（顾炎武、王夫之等把学问引向国计民生）。
- **分析（箭头）**：**正因为**资源有限、问题真实，**所以**“有用”的追问本身是一种责任，而非功利。
- **限定**：但“有用”若成了唯一的尺子，它就会反过来裁剪掉一切还不能被计价的东西。
- **回扣**：承认有用，是清醒；把有用当唯一标准，是短视。

### 主体段 2：无用的价值，在于“已知之外”（判境 / 本质）
- **观点句**：无用之物，是替“未知”预留的那扇门。
- **阐释**：已知的用处只解决已知的问题；而真正的超越，往往来自一个当时看不出用处的念头。
- **材料**：屠呦呦从东晋葛洪《肘后备急方》“青蒿一握，以水二升渍，绞取汁”里得到低温提取的灵感，一句古书里的“偏方”，在千年后被证明是救命的钥匙。
- **分析（箭头）**：**如果**当年有人以“有用”为标准，把这些看似荒诞的古方清掉，**那么**青蒿素也就失去了那条线索。**正因为**“无用”的东西被保留下来，未来才有可捡的东西。
- **限定**：当然，不是所有无用都终将有用，保留无用，是**购买一种可能性**，而非保证收益。
- **回扣**：无用的价值，不在兑现，而在留白。

### 主体段 3：怎么对待“无用”（破境 / 怎么办）
- **观点句**：给无用留一点时间，是个人和社会都该有的“长期主义”。
- **阐释**：转化不会自动发生，它需要时间，也需要不急着要答案的人。
- **材料**：徐霞客三十年游历，当时既无官职也无实利，却留下《徐霞客游记》，成为后世地理学的珍贵文本。
- **分析（箭头）**：**正因为他**没有把每一步都折算成功名，**才**走出了一条当时看不见、后来却极有用的路。
- **具体动作**：与其把每一分钟都排进日程，不如每天留半小时给“暂时看不出用”的阅读与思考。
- **回扣**：真正的远见，是肯为不确定的未来先付一点耐心。

### 结尾（约 100 字）
- **修正式收束**：无用与有用之间，隔着一条时间的河。站在岸边算账的人，只能看见此刻；愿意等的人，才能看见对岸。

### 提纲小结

| 段 | 论证动作 | 那根“箭头” |
|---|---|---|
| 主体 1 | 承认有用 | 资源有限 → “有用”的追问是责任 |
| 主体 2 | 揭示无用的本质 | 若只留有用 → 未来无可捡 → 故须留白 |
| 主体 3 | 怎么办 | 不折算成功名 → 走出后来有用的路 |

### 下一步
- 按这份提纲自己写一版（推荐）；
- 或说“**按这份提纲写一篇范文**”。
```

## 对话样本 · 第二轮 · 范文写作

### 学生输入

> 老师，按这份提纲写一篇范文给我看看。

---

### Skill 输出（M4 · 范文写作）

```markdown
## 范文

### 无用的时间，有用的远方

我们习惯用“有没有用”给一切定价：读书要读能提分的，做事要做有回报的，连闲下来，也要问一句“这有什么用”。可“有用”与“无用”从来不是两样东西，它们只是同一样东西，在两个时间刻度上的名字。在我看来，**无用的价值不在眼前，而在它替未来保留了可能性；给无用留一点时间，就是给超越自己留一条路。**

崇尚“有用”，并不浅薄。它是文明得以运转的务实底色。明清之际的思想家提出“经世致用”，正是为了纠正空谈心性的学风，让学问回到国计民生上来。**正因为资源有限、问题真实，“有用”的追问才是一种责任，而不是功利。** 但任何尺子，一旦成了唯一的尺子，就会反过来裁剪世界：当“能不能立刻用上”成了唯一的评判，那些还不能被计价的东西，就会先被清出去。承认有用，是清醒；把有用当成唯一标准，却是短视。

而无用之物，恰恰是替“未知”预留的那扇门。已知的用处，只能解决已知的问题；真正的超越，往往来自一个当时看不出用处的念头。屠呦呦翻检东晋葛洪《肘后备急方》，读到“青蒿一握，以水二升渍，绞取汁，尽服之”，从中得到低温提取的灵感。那是一句躺在古书里、几乎无人问津的“偏方”。**如果当年有人以“有用”为标准，把这类看似荒诞的旧方一并清掉，那么青蒿素也就失去了它最初的线索。正因为这些“无用”被保留下来，未来才有东西可捡。** 当然，并非所有无用都终将有用，保留无用，是购买一种可能性，而不是保证一笔收益。它的价值，本就不在兑现，而在留白。

可可能性不会自动变成现实。它需要时间，也需要不急着要答案的人。徐霞客三十年远游，不走仕途，不谋实利，在当时看来近乎“不务正业”；可正是这部由行走写成的《徐霞客游记》，成了后世地理学绕不开的文本。**正因为他没有把每一步都折算成功名，才走出了一条当时看不见、后来却极有用的路。** 对我们而言，这意味着一种具体的选择：与其把每一分钟都排进日程，不如每天留半小时，给暂时看不出用处的阅读与思考。远见，从来不是算得更准，而是肯为不确定的未来先付一点耐心。

无用与有用之间，隔着一条时间的河。站在岸边算账的人，只能看见此刻；愿意等的人，才能看见对岸。愿我们都不必急着把今天的一切，都兑换成明天的用处。

---

（全文约 880 字）

## 结构透视

| 段 | 论证动作 | 关键“箭头” / 亮点 |
|---|---|---|
| 开头 | 建立问题 + 亮观点 | 把“有用/无用”重定义为“同一样东西的两个时间刻度” |
| 主体 1 | 承认有用 | **正因为资源有限、问题真实**，先立后破，不偏激 |
| 主体 2 | 揭示无用的本质 | **如果清掉无用，未来就无可捡**，反证法；有**限定**（购买可能性，非保证收益） |
| 主体 3 | 怎么办 | **正因为没折算成功名，才走出后来有用的路**，并落到“每天半小时” |
| 结尾 | 修正式收束 | “时间的河”回扣开头，不喊口号 |

## 语言风格说明（供对照，不必照搬）

1. **说人话**：“算账”“留白”“有东西可捡”都是日常词，不堆大词。
2. **箭头外显**：三处“正因为……才……”“如果……那么……”，把逻辑写在纸面上。
3. **限定/反驳**：主体 2 有“当然，并非所有无用都终将有用”，这是**一类文的分水岭**。
4. **不强行升华**：结尾用“修正”收束，没有“愿我辈青年”的空呼吁。

## 写作提醒

- **不要抄**：抄原文到考场＝套作，直接判低分。
- 正确用法：**看懂骨架 → 理解箭头 → 用自己的话重写**。
- 建议先不看范文，按提纲自己写一版，写完再对照。
```

## 附录 · 这个示例展示了什么

### 审题 / 提纲阶段（M1 + M3）
1. 关系型材料先抓“关系”（如何转化），不纠缠“哪个更重要”。
2. 给 2–3 个标题候选，不一锤定音。
3. 每个分论点都写清“凭什么成立”（那根箭头）。
4. 用论证段落闭环（观点→阐释→材料→分析→限定→回扣），不是僵化的五句一段。
5. 素材先查 `resources/01`（屠呦呦、徐霞客）；概念类可查 `resources/06-人与自我素材精编.md`。

### 范文阶段（M4）
6. 范文严格按提纲写，850–1000 字。
7. 附结构透视，标出箭头与限定。
8. 主动提醒“不要抄袭”，给出正确参考用法。
9. 不强行“君不见”排比，也不强行“吾辈青年”结尾。

### 与年级范文的对照
- 同题的一份年级范文《“有用”与“无用”》（见作者语料库，原作者保留版权）走了另一条路：从“重新定义有用/无用”入手，指出二者是“瞬时的、主观的概念”，再落到“功利主义的咽喉”。
- 两种写法都对：本例走“时间维度”（无用替未来留白），范文走“定义维度”（有用无用由谁定义）。**同样的骨架，可以长出不同的文章。**

## 这个示例没展示（但 Skill 应做的）

- 学生要“换个素材重写”：按同样骨架换素材。
- 学生说“这段看不懂”：拆成“观点→阐释→材料→分析→限定→回扣”逐句讲。
- 学生问“这篇范文多少分”：按批改标准自评（本篇约 53–55，一类下：论证清楚、有思辨、语言说人话）。
