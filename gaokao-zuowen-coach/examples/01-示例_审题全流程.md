# 示例 · 审题全流程

> 一个完整的"学生发题 → Skill 审题 → 学生提立意 → Skill 打磨"的走查。
> 重点示范：题眼（关键词之间的关系）、合理生发、以及"每个分论点凭什么成立"。
>
> 版权：本题取自作者所在学校的高二大作文讲义（题目为公共考试材料），讲义原文的分析文字版权归编者所有，此处仅用其题目，分析为 Skill 另作。

---

## 对话样本

### 学生输入

> 老师，帮我审一下这道作文题：
>
> 阅读下面的材料，根据要求写作。
>
> 古语云"父母在，不远游"，其后半句"游必有方（若远游，定要告知父母所去的方向）"常被忽略。熟语云"不听老人言，吃亏在眼前"，而后半句"尽信老人言，终生难向前"却鲜为人知。
>
> 以上材料引发了你怎样的联想和思考？请写一篇文章。
>
> 要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不少于 800 字。

---

### Skill 输出（M1 · 审题诊断）

```markdown
## 审题报告：关于"被忽略的后半句"

### 一、材料核心与题眼

- **核心话题**：传统古语被"腰斩"、断章取义的文化现象。
- **材料结构**：
  - 第 1 组："父母在，不远游"（常见）＋"游必有方"（被忽略），**孝道**被抽走了"有方"的理性维度
  - 第 2 组："不听老人言"（常见）＋"尽信老人言，终生难向前"（鲜为人知），**经验**被抽走了"独立判断"的平衡
  - 关系：**并列 + 同构**，两组都是"前半句流传、后半句失落"，共同指向同一个现象
- **题眼（关键词之间的关系）**：不是"孝道"，也不是"独立"，而是 **"常被忽略""鲜为人知"所描述的那个现象**，
  为什么在传播中，修正、平衡的后半句会先被丢掉？丢掉之后，传统智慧变成了什么？
- **隐性限定**：**严禁**单独论述"孝道""独立"。离开"前后半句、被忽略"这个核心，即偏题或跑题。

### 二、关键概念具体化

| 关键词 | 在本题中的具体含义 | 常见误解 |
|---|---|---|
| 常被忽略 / 鲜为人知 | 一种**主动或被动地只接受一半**的传播现象 | 误解为"大家记性差""记不住" |
| 后半句 | 起**修正、平衡**作用的那一半 | 误解为"更正确的答案" |
| 游必有方 | 远游要有方向、有交代，是孝的理性维度 | 误解为"允许远游"的通行证 |
| 尽信老人言，终生难向前 | 对经验也要保持独立判断 | 误解为"否定老人言" |

### 三、提示语任务清单

- [ ] 身份 / 对象 / 场景：无（默认高中生视角）
- [ ] 文体："明确文体"，议论文最优
- [ ] 字数：≥800
- [ ] "联想和思考"：**有**，须由古语现象扩到当代（信息、标题党、碎片化）
- [ ] "结合材料"：**有**，不能脱离"被忽略的后半句"
- [ ] 隐性限定：**有**，论述对象只有一个核心，不许换成"孝道"或"独立"

### 四、立意建议（3 选 1）

#### 立意 1：读懂"后半句"，才是对传统的真正传承 ⭐（最稳妥）
- **切入视角**：认知论（完整 vs 片面）＋ 价值论（传统如何活着）
- **中心句**：真正的传承不是背下那句最响亮的箴言，而是把它失落的后半句找回来，在"取"与"舍"之间读懂传统的分寸。
- **分论点骨架（每个都写清"凭什么成立"）**：
  1. 前半句被留下、后半句被丢掉，是传播规律与认知惰性共同作用，**凭什么**：简洁有力的更易流传，而修正、平衡的后半句不便记忆、不符说教。
  2. 只剩一半的古语，会把辩证智慧扭成极端教条，**凭什么**：抽掉"游必有方"，"孝"就成了禁锢；抽掉"尽信则难向前"，"敬"就成了盲从。
  3. 找回后半句，靠的是主动的"完整阅读"，**凭什么**：传统不是标准答案，而是需要在具体情境里把握的"度"。
- **难度与特色**：稳、正、易落地，考场上最不容易失手。

#### 立意 2：从"被忽略的后半句"反思文化传承中的"减损"
- **切入视角**：困境论（传承为何走样）＋ 边界论
- **中心句**：传统在流传中不断"减半"，减掉的恰恰是它最清醒的那部分；传承的第一功课，是抵抗这种减损。
- **分论点骨架**：
  1. 减损有其结构原因，**凭什么**：被传播的往往是最便于规训、最便于记忆的那一半。
  2. 减损的后果是思辨精神流失，**凭什么**：教条不需要思考，平衡才需要。
  3. 对抗减损，要重建"完整"的意识，**凭什么**：只有把话放回原来的语境，才谈得上理解。
- **难度与特色**：现象分析深，容易出彩，但要注意别写成"批判传统文化"。

#### 立意 3：守正与出新，传统智慧的当代生命力
- **切入视角**：发展论（传统的再生）
- **中心句**：传统的生命力，不在它被完整背诵，而在它被完整理解之后，还能被重新实践。
- **分论点骨架**：
  1. 守正：先理解核心精神，**凭什么**：不理解就谈不上下判断。
  2. 出新：在新的时代条件下重新实践，**凭什么**：传统本就是在具体情境中把握"度"的艺术。
  3. 二者结合，才有活的传统，**凭什么**：只守不出则僵，只出无守则空。
- **难度与特色**：格局大，但容易空泛，需靠具体例子撑住。

### 五、常见写偏的陷阱（针对本题）

1. **换成"孝道"或"独立"**，只抓一句的前半句，完全脱离"被忽略"现象，直接偏题。
2. **把"被忽略"理解成"记性差"**，停在"大家要多背古语"，没进"为什么会被丢掉"。
3. **两边各打五十大板**，"既要听老人言，也要独立"，写成"既要又要"的废话，没有张力。
4. **另起炉灶谈"创新"**，从"后半句"跳到"创新是第一动力"，与材料只有字面联系。
5. **起笔宏大**，开头"纵观五千年文明史"，容易高开低走。

### 六、下一步
选定立意后对我说："**上面那道题，我选立意 X，帮我列提纲**"，我会按**论证段落闭环**（观点→阐释→材料→分析→限定→回扣）给出提纲。

> 相关资源：本题属"传统 · 创新 · 传承与突破"原型，见 `resources/03-话题原型库.md` 原型 3；素材可从 `resources/01-人物素材库.md`（孔子、徐霞客、李时珍）与 `resources/02-名句素材库.md` 调取。
```

## 学生的追问 · 立意打磨

### 学生输入

> 老师，我想写"年轻人应该多听老人言，因为长辈的经验很宝贵"。这样行不行？

---

### Skill 输出（M2 · 立意打磨）

```markdown
## 立意诊断

**你的立意**：年轻人应该多听老人言，因为长辈的经验很宝贵。

### 诊断结果：⚠️ 方向偏移，接近"另起炉灶"，需要调整

**判据**：你的主张（多听老人言）**正是材料要批判的那一半**。材料把"不听老人言，吃亏在眼前"和"尽信老人言，终生难向前"并置，问的不是"要不要听老人言"，而是"**为什么后半句会被忽略**"。你回答的，是材料已经否定的那个结论。

#### 优点
1. 你抓住了"经验"这个材料要素，方向不算全错。
2. 你的主张有真实的生活依据，不空。

#### 问题
1. **丢了核心**：题目考的是"被忽略的后半句"这个**现象**，你把它换成了"该不该听老人言"这个**观点**。
2. **只用了半句材料**：第二组的后半句你完全没接。
3. **没有张力**：这是一句表态，不是一道辨析。

#### 三条优化建议
1. **把"主张"改回"现象"**：不要问"该不该听"，要问"为什么'尽信则难向前'会被丢掉"。
2. **两组材料都用上**：从"游必有方"和"尽信难向前"里，找出共同的机制，**修正性的后半句，总是最先失落**。
3. **补上你自己的判断**：现象之后要有观点，例如"找回后半句，是对传统的真正尊重"。

#### 替代立意

**立意 A（保留你的"经验"关切）：听，但不尽信**
- 中心句：经验值得敬畏，但敬畏不等于服从；"尽信老人言，终生难向前"这半句，正是传统留给我们的清醒。
- 分论点：① 前半句教我们尊重经验（**凭什么**：经验是他人替我们付过的学费）② 后半句教我们保留判断（**凭什么**：经验有它的时代边界）③ 完整理解二者，才是对传统与自己的双重负责。

**立意 B（顺材料现象走）：被丢掉的那半句，最该被捡回**
- 中心句：传统在流传中被"腰斩"，而丢掉的往往是它最清醒的平衡；传承的第一步，是把话读完整。
- 分论点：① 现象：修正性的后半句为何先失落 ② 后果：只剩一半的箴言如何变成教条 ③ 出路：重建"完整阅读"的意识。

### 下一步
你可以：选替代立意 A 或 B；或告诉我你想保留原立意里的哪些元素（比如"经验很宝贵"），我们再调一版。
```

## 附录 · 这个示例展示了什么

1. **先找题眼**：真正限制方向的是"常被忽略 / 鲜为人知"这个**现象**，不是"孝道"或"独立"。
2. **三叩审题法走全**：材料 → 提示语 → 自己，并标出隐性限定（严禁换成单一话题）。
3. **概念具体化**：用"具体含义 vs 常见误解"表，把"被忽略"和"记不住"区分开。
4. **每个分论点都写"凭什么成立"**，这是新版 Skill 的核心要求。
5. **诊断学生立意时先判"是否另起炉灶"**，本例更严重，学生的主张恰是材料批判的对象。
6. **不只否定，给替代方案**，并尽量保留学生思路里可用的部分（"经验"这个关切）。

## 这个示例没展示（但 Skill 应做的）

- 学生直接要"3 个立意"：跳过对话，直接给 M1 的立意表。
- 学生给的题目有歧义：在评价开头注明"本次基于文本内推测的主题，如题目另有说明，结论可能不同"。
- 学生要求把审题写进 Word：走 `references/09-docx输出.md` 的审题报告拼装。
