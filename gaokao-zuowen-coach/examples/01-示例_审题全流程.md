# 示例 · 审题全流程

> 一个完整的"学生发题 → Skill 审题 → 学生提立意 → Skill 打磨"的走查。
> 重点示范题眼、合理生发、三境七论、以及"分论点凭什么成立"，这是新版 Skill 与旧版最大的不同。

---

## 对话样本

### 学生输入

> 老师，帮我审一下这道作文题：
>
> 阅读下面的材料，根据要求写作。（60 分）
>
> "最重要"一词，常被我们用以确立事物的优先级，然而，对"最重要"的判断往往随立场、境遇而改变。还有人指出，当我们不断宣称某事物"最重要"时，正暴露了它在现实中的稀缺与脆弱。
>
> 以上材料引发了你怎样的联想和思考？请写一篇文章。
>
> 要求：选准角度，确定立意，明确文体，自拟标题；不要套作，不得抄袭；不少于 800 字。

---

### Skill 输出（M1 · 审题诊断）

```markdown
## 审题报告：关于"最重要"的流变与悖论

### 一、材料核心与题眼

- **核心话题**：对"最重要"（价值优先级）的判断
- **材料结构**：
  - 第 1 句："最重要"随立场、境遇而改变——**观察/判断**（流变性）
  - 第 2 句：反复宣称"最重要"暴露其稀缺与脆弱——**观察/判断**（宣称悖论）
  - 关系：**递进 + 辩证**——从"主体视角"推进到"宣称现象"，两者同指一个概念的不同侧面
- **题眼（关键词之间的关系）**：不是"最重要"三个字，而是 **"流变"与"稀缺"之间的张力**——
  既然它随境遇而变，为什么我们还要反复宣称？**"变"与"宣称"的矛盾，就是本题真正的入口。**
- **隐性限定**：无（但材料对"反复宣称"带轻微批判色彩，立论不宜停在"多喊几遍很重要"）

### 二、关键概念具体化

| 关键词 | 在本题中的具体含义 | 常见误解 |
|---|---|---|
| 最重要 | **优先级最高者** | 误解为"很重要""所有关键事物" |
| 立场 / 境遇 | 主体所处的位置、处境、阶段 | 泛化为"对错""命运" |
| 稀缺 / 脆弱 | 现实中缺乏、难以长久持有 | 泛化为"珍贵""感情脆弱" |
| 宣称 | **用语言反复强调** | 忽略其"反复"的行为特征 |

### 三、提示语任务清单

- [ ] 身份 / 对象 / 场景：无（默认高中生视角，广义读者）
- [ ] 文体："明确文体"——议论文最优
- [ ] 字数：≥800
- [ ] "联想和思考"发散指令：**有**——须调动古今、扩展到当代现实
- [ ] "结合材料"收敛指令：**有**——不能脱离材料
- [ ] 隐性限定：无

### 四、立意建议（3 选 1）

#### 立意 1：执一而应万——在流变中守护永恒 ⭐
- **切入视角**：关系论（变与不变）+ 价值论（超越价值）
- **中心句**：真正的智慧，不是找到一个永恒不变的"最重要"并奉为圭臬，而是在变动中锚定价值、在稀缺中以行动守护。
- **分论点骨架（每个都写清"凭什么成立"）**：
  1. "最重要"随立场境遇而变——**凭什么**：人的需求本身是动态的，优先级只是需求的映射。
  2. 反复宣称"最重要"暴露其稀缺——**凭什么**：语言是补偿机制，越缺什么越强调什么。
  3. 以"内核守一"应"表象万变"——**凭什么**：只有把价值锚定在自身行动上，才不受外界排序牵动。
- **难度与特色**：有挑战、出彩——辩证处理好易上一类；处理不好易三段平行。

#### 立意 2："最重要"不是唯一答案
- **切入视角**：认知论（自我/他者）
- **中心句**："最重要"不是僵化的标签，而是流动的智慧；不应是稀缺的焦虑，而应是行动的号角。
- **分论点骨架**：
  1. 它是主体与情境互动的产物——**凭什么**：同一个人在不同阶段会给出不同排序。
  2. 反复宣称暴露稀缺的社会心理——**凭什么**：强调行为本身泄漏了缺口。
  3. 以行动代替强调——**凭什么**：行动是唯一能真正改变稀缺的手段。
- **难度与特色**：中等、稳妥，但易写成模板。

#### 立意 3：守住你的"最重要"——脆弱之中的顽强
- **切入视角**：价值论（永恒价值）+ 困境论
- **中心句**：有些"最重要"随境遇而变，自合理；但有些代表普适价值，正因稀缺才需守护。
- **分论点骨架**：
  1. 个体之"最重要"随阶段分化——**凭什么**：主体不同、需求不同。
  2. 普适价值之"最重要"因稀缺而脆弱——**凭什么**：和平、自由、公正在现实中从不自动在场。
  3. 破局在你我——**凭什么**：守护需要具体行动而非口号。
- **难度与特色**：偏抒情、有诗意，适合语言功底好的学生。

### 五、常见写偏的陷阱（针对本题）
1. **把"最重要"等同于"很关键"**——脱离"优先级 + 流变 + 稀缺"核心。
2. **只抓一句**——只写"随境遇而变"或只写"宣称暴露稀缺"，两句话的关系没理清。
3. **论证平行化**——三个分论点都是同一句的同义反复，认识没有向前移动。
4. **另起炉灶**——转向"做自己""寻找自我"，与"最重要"只有字面联系（见下）。
5. **宏大起笔**——开头"纵观人类历史"，容易高开低走、被判"拧巴"。

### 六、下一步
选定立意后对我说："**上面那道题，我选立意 X，帮我列提纲**"，我会按**论证段落闭环**（观点→阐释→材料→分析→限定→回扣）给出提纲。
```

## 学生的追问 · 立意打磨

### 学生输入

> 老师，我想写："每个人都要找到自己的最重要，不要被别人的最重要绑架。" 这样行不行？

---

### Skill 输出（M2 · 立意打磨）

```markdown
## 立意诊断

**你的立意**：每个人都要找到自己的最重要，不要被别人的最重要绑架。

### 诊断结果：⚠️ 方向偏移，接近"另起炉灶"，需要调整

**判据**：你引入的核心是"自我主体性 / 反绑架"，它与题目的核心概念"最重要（优先级）"**只有字面交集**——
题目问的是"为什么价值排序会变、为什么反复宣称会暴露稀缺"，你回答的是"要做自己"。
**这属于换了文章真正处理的问题。**

#### 优点
1. 有真实的问题意识——"被别人的最重要裹挟"是当代青年的切身困境。
2. 能自然落到"怎么办"，对高中生有意义。

#### 问题
1. **绕开了材料第 2 句**——"反复宣称暴露稀缺"完全没进你的视野，材料要素丢失一半。
2. **方向偏到"做自己"**——这是另一个母题（人与自我），不是"最重要"的题域。
3. **辩证不足**——你的立意是一句结论，缺少"什么时候应当听从他人的最重要"的讨论。

#### 三条优化建议
1. **把两句材料都用上**：改为"既要在流变中找到自己的排序，也要警惕'被反复强调'的稀缺"。
2. **紧扣"优先级"**：把"最重要"明确限定为**优先级**，而非"自我"。→ "每个人应根据自身阶段重新排列优先级，不必被他人的排序绑架。"
3. **补上辩证**：承认"某些集体性的最重要（家国、公德）不该被'自己的最重要'取代"，避免滑向极端个人主义。

#### 替代立意

**立意 A：执衡而行，不困于他人之"最重要"**
- 中心句：真正的成熟，是既不被他人绑架，也不走向唯我——而是"辩证倾听"。
- 分论点：① 他人之"最重要"值得倾听（**凭什么**：它是立场与境遇的经验）② 但不应被绑架（**凭什么**：每个人的境遇不同）③ 破局在择其扣合自身者而取之。

**立意 B：在流变中守护真正属于自己的那一份**
- 中心句：借助"反复宣称暴露稀缺"这一洞察，识别并守护真正的"最重要"。
- 分论点：① 流变揭示其主观性 ② 被反复强调的，正是我们以为拥有实则缺少的 ③ 以行动代替强调。

### 下一步
你可以：选替代立意 A 或 B；或告诉我你想保留原立意的哪些元素，我们再调一版。
```

## 附录 · 这个示例展示了什么

1. 先找题眼，真正限制方向的是"流变"与"宣称"之间的张力，不是"最重要"三个字。
2. 三叩审题法走全，材料、提示语、自己。
3. 概念具体化，用"具体含义 vs 常见误解"表。
4. 每个分论点都写"凭什么成立"，这是新版的核心要求。
5. 诊断学生立意时先判"是否另起炉灶"，指出"与题目只有字面交集"。
6. 给替代方案，不只否定，帮学生保留思路里的好东西。
