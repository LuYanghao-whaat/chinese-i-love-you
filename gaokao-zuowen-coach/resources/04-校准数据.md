# 校准数据（作者个人）

> 本文件是作者的个人校准数据，不是评分标准。
> 用途：防止批改时分数漂移，帮助 Skill 贴合作者的真实水平带。
> 原则：`references/` 里的评分标准保持概括性，不引用具体篇目；具体数据只放在这里。

## 一、正常议论文分数样本

| 题目 | 分数 | 简述 |
|---|---|---|
| 向湖中射箭 | 55（一类下） | 思辨型，**通篇无人物素材**，靠论证与语言取胜 |
| 经世致用 / 无用之用 | 53–56（一类下） | 材料作文，稳定在一类 |
| 追寻真相（一） | 53（一类下） | 哲理型，意象贯穿全文 |
| 坏逻辑 | 53（一类下） | 条理清晰，概念界定 + 归因 |
| 拆鸟巢（书信） | 52（一类下，统批） | 第二人称，任务完成度高（考场作文） |
| 乱拳打死老师傅 | 51（二类上） | 观点新颖，但论证有跳跃 |
| 重视 / 放下自我 | 51（二类上）／四十几 | **同文分差极大**——起笔宏大，被判“偏题错觉、生硬” |
| 追寻真相（二，同题另写） | 45（二类下）／48 | 与“追寻真相（一）”同题，构思方向不同，差 5–8 分 |

不纳入校准：体裁创新 / 非议论文（故事新编、小说、演讲稿等）分数波动大或不参与评分。

## 二、阅卷者严格度

- 不同阅卷者的严格程度不同：阅卷者甲 > 统批 > 阅卷者乙。
- 其中一位给分不稳、可能受情绪影响；其分数偏高时，参考其他阅卷者更稳。

## 三、写作者倾向（用于校准批改重点）

- 常被夸：思辨深度 / 立意新颖、结构清晰。
- 常被骂：论证跳跃（箭头断）、起笔宏大（偏题错觉）、素材堆砌。
- 当前主要毛病：偏“人文主义”，用比喻等修辞替代论证。

> 以上均为趋势性描述，不指向任何单篇。
