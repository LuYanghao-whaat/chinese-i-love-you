# 核心审题法

> 作文写砸，九成不是写不出来，而是没审清楚。
> 但"审清楚"不只是"读懂材料说了什么"，而是判断它真正要求你解决什么问题。

本文件是 Skill 执行审题诊断（M1）、立意打磨（M2） 时必须先读的方法论。
它对应新高考评价里的内容项（切合题意、中心突出、思想健康），决定文章的下限。

---

## 一、第一判断：合理生发，还是另起炉灶？

这是应试作文的两个极端：合理生发可达 54，另起炉灶可低至 34。

一句话判据：有没有脱离题给的主题。

两者长得很像，都引入了新概念、貌似都在话题之下。区别在于：

- 合理生发：新引入的概念 D，与题目关键词 A/B/C 有交集、可直接建立联系。
- 另起炉灶：D 与 A/B/C 无关、自成一派，看似在同一话题，实则换了文章真正处理的问题。

例：
- 谈"实力"，引入"发展力"，只要认识到"发展力是实力的一种"并加以论述，就是合理生发。
- 谈"直行"与"曲行"，引入"自成道路"，若意识到"直""曲"统摄于"自成之路"之下，反而写得好；若把"自成道路"当成三者之外的第四种，就偏了。
- "本手/妙手/俗手"题：论证"本手不一定是妙手""俗手也可成妙手"都没问题；但若说"还有在三者之外的某某手"，就危险了，关键在脱不脱离题目关键词。

另起炉灶不是绝对不可用：可用于加深思想性，但建议不超过 100 字，且必须与题目建立可说明的联系。

一个更狠的检验：看文章处理的是"特殊问题"还是"通用问题"。
题目问的通常是一个特殊问题（有具体情境、具体矛盾）；好文章回答这个特殊问题，
另起炉灶的文章回答的是一个更一般的、放之四海皆准的问题。
把材料换掉、中心主张照样成立，就是没在回答这道题。

## 二、题眼：限制文章方向的，往往不是单个关键词，而是关键词之间的关系

不要只圈关键词，要圈关系。

- "本手、妙手、俗手"，题眼是三者之间的转化关系，不是"妙手好"。
- "有时需要重视自我，有时也需要放下自我"，题眼是那个"有时"，即条件。
- "向湖中射箭，成绩永远是十环"，题眼是"永远"与"无靶之靶"背后的张力。

操作：拿到题，先问一句，这几个关键词之间，是并列、递进、转折、因果、对立，还是辩证？把关系写出来，方向就稳了。

## 三、三立原则（写作前的地基）

### 1. 立概念：关键概念必须具体化

不能用"字典释义"去写，必须结合材料把它限定到最精准的那个含义。

反例：题目谈"最重要"，学生把它当成"很关键的东西"，大谈"友谊最重要""健康最重要"。
正例："最重要"在题中指事物的优先级，要围绕"优先级为什么流变""被反复强调的为何恰恰稀缺"来写。

操作：
1. 圈出每一个关键词；
2. 对每个词问：在这则材料的语境里，它被限定到哪一层？
3. 把这一层含义写在草稿纸上；
4. 后文每次提到它，都确认用的是这一层含义。

> 更进阶的界定方法（否定法、语境法、属加种差、拆字、判准），见 `05-论证技法.md` 第二节。

### 2. 立事实：现象必须展开分析

材料里的现象/事实，不能只"引用一下"就带过。三层分析：为什么发生？反映了什么深层问题？带来什么影响 / 合理吗？

### 3. 立观点：所有观点必须证明

中心论点、分论点、段内小结论，都不能"光亮不证"。
但"证明"不等于"举例"，例子和观点之间必须有一条你自己铺的逻辑道路。素材不是论证。（详见 `05-论证技法.md`）

## 四、三个容易被忽略的意识

### 1. 条件意识

很多作文真正的问题不是"A 还是 B"，而是"什么时候 A，什么时候 B"。
> "坚持"对还是"变通"对？看条件：在原则问题上坚持，在方法问题上变通。

有了条件，观点才能落地，才能避开"两边都重要"的空话。

### 2. 论域：明确文章究竟在谈个人、社会、时代还是伦理

防止暗中换赛道。开头谈个人修养，中间突然跳到"时代洪流""人类文明"，读者会觉得你跑题了。
同一篇文章的论域应当基本一致；要升级，必须有明确的过渡。

### 3. 问题设定权

材料默认的问法，未必是唯一的问法。你可以意识到并回应它，但要先回答材料的问题，再谈你重新设定的问题。
> 材料问"这句话对不对"，你可以先回答，再追问"我们为什么会需要这样一句话"。
> 注意：重设问题不是无视问题；一旦丢掉材料原问题，就是另起炉灶。

## 五、母题意识（把题放进更大的问题里）

高考作文的母题大致有：人与自然、人与社会、人与自我、人与科技。

母题不是模板，只是问题索引，不负责预先给答案。它的作用是：让你更快找到观察问题的角度。
> "科技时代问题更多还是更少"、"敬自己"，都可归入某个母题之下。

真正有意思的立意，往往产生于两个母题的交界处。

## 六、三境七论（破题与立意的核心工具）

单一母题太笼统，用"三境七论"把它拆成更具体、可操作的论点。三境＝文章的思考阶段，七论＝七个观察视角。

### 一阶 · 观境，观全局，定坐标

① 关系论（关键词：主客 / 代际 / 矛盾）
- 主客关系：区分主动与被动。谁在评价？谁被评价？"敬自己"中，"我"从被他人评价的客体，变成了评价自己的主体，主客发生了转换，这就是一个论点。
- 代际关系：过去 / 当下 / 未来（不是辈分）。
- 矛盾关系：二者究竟"冲突"在哪，要具体说出冲突来源，不能只宣布"存在矛盾"。

② 认知论（关键词：自我 / 他者 / 世界）
"我"如何认知自己？"他者"如何认知"我"？"我"如何认知世界？
可用理论：镜中我（库利）、洞穴比喻（柏拉图）、心外无物（王阳明）、格物致知（《大学》）。

### 二阶 · 判境，据现象，析原因

③ 困境论（关键词：认知 / 成长 / 时代），回答"为什么问题是这样"。
- 认知困境：事物超出认知边界或打破固有价值体系，使人迷茫。
- 成长困境（"转变困境"更准）：发现问题、渴望改变，但改变难以实施，无力的来源。
- 时代困境：时代笼罩于个人之上的结构性阴影，如绩点主义、绩效社会。

④ 价值论（关键词：功利 / 超越 / 永恒），同一事物在不同尺度下价值不同。
- 功利价值：世俗眼光，常作批判对象（如"重建古塔劳民伤财"）。
- 超越价值：长远的文化、人文、情绪价值（如西西弗斯推石的幸福）。
- 永恒价值：与"人类历史"同量级，慎用，大谈容易空泛。

### 三阶 · 破境，对原因，找方法

⑤ 方法论（关键词：实践 / 思维 / 工具）
- 实践：具体可操作的方案（"制定安排表"是实践，"行动"不是）。
- 思维：观念转变（如"心中埋下种子，表面顺从体系"）。
- 工具：借力达成的桥梁（"好风凭借力，送我上青云"）。

⑥ 边界论：事物不可越过的边界，越过即异化。（偏宏大、涉政，慎用）

⑦ 发展论：动态、扬弃、革故鼎新。"逆水行舟，不进则退"。

### 使用铁律

1. 一篇作文只用 2–3 个论点，用上其中几个形成分论点即可。
2. 不能把哲学概念硬往文题上靠，否则会"拧巴"。
3. 不能先入为主：除了人尽皆知的观点（如西西弗斯），引用理论前必须先阐明这个理论如何适用于本题。阅卷者不是天才。
4. 哲学家的名字没有论证效力。概念是用来发现问题的镜头，不是权威背书。

## 七、"单元作文"怎么生发（只有一个核心概念时）

题目只给一个名词（实力、定位、悲悯），大多数考生草草写三个平庸观点就弹尽粮绝。用以下关系打开：

### ① 分类关系
把概念分类。如"实力"→国家 / 社会 / 个人。

### ② 对立关系
引入相对立的概念。常见层次：正反、真假、古今、表里、内外、时空、理性与感性、自我与外界、适度/过少/过多、主客。

### ③ 客体关系（下定义、提方法时用）
- 这个东西本质是什么？
- 涉及哪些角色：产生者、评价者、被评价者、定义者、维护者、执行者、逆行者？
- 主观性 / 客观性 / 社会环境？

### ④ 结构关系（不要走偏锋，小心政审）
"这也许是某些结构性问题的具象化表现？"，人作为社会性动物、严肃问题娱乐化、背后有更强大/原始的力量在操控。

## 八、两种高危写法

### 1. 宏大起笔风险

起笔过大（"纵观人类文明史……"），容易出现先跑离题目、再努力返回赛道的"拧巴"。
正确顺序：先在扣题的基础上生发，把小的生发成大的；不要先写大的再落回小的。

### 2. 结构性偏题

表面上拥有题目关键词，也可能因为生发方向错误而产生偏题错觉。
关键词在，不等于题目在。每写一段都回问：这一段是在回答题目真正的问题吗？

## 九、三叩审题法（完整执行流程）

### 第一叩：叩问材料

1. 材料围绕什么话题？一句话写出来。
2. 是事实/现象、观点/判断，还是两者都有？
3. 多句话之间什么关系？（并列/递进/转折/因果/对立/辩证）
4. 发生在什么情境（背景、条件）下？
5. 涉及哪些人/要素？主要的是谁？
6. 为什么会出现这个现象/观点？

关键：多句材料不能只抓前半句；典型陷阱是"前半句现象、后半句观点"，学生只分析现象、不证明观点。

### 第二叩：叩问提示语

1. 有没有提示语？（"以上材料引发了你怎样的联想和思考"）
2. 布置了哪些任务？
   - 身份：以什么身份写？
   - 对象：写给谁？
   - 场景：什么场合？
   - 目的：呼吁/说明/反思？
   - 主题：核心谈什么？
3. 有没有"联想和思考"发散指令？（有→调动储备、扩展到现实）
4. 有没有"结合材料"收敛指令？（有→全文不能脱离材料）
5. 有没有"自拟标题""自选角度"自由度指令？

把所有任务列成清单，逐项打勾。漏一个可能降一档。

> 隐性限定同样重要：若题干或评分要求里写了"不得批判某观点""应体现某身份"之类，这属于硬约束，必须遵守（它常常比显性任务更能决定分数）。

### 第三叩：叩问自己（立意 → 骨架 → 细节）

1. 我的立意是什么？（一句话，不超过 25 字）
2. 中心句怎么写？
3. 设几个分论点？（一般 3 个）
4. 分论点之间什么关系？（层进 / 对照 / 辩证，见 `02-段落与结构.md`）
5. 每个分论点要证明什么？凭什么成立？
6. 开头怎么建立真正的问题？
7. 结尾怎么完成修正 / 回扣 / 开放？

## 十、常见审题陷阱

| 陷阱 | 表现 | 后果 | 对策 |
|---|---|---|---|
| **关键概念悬空** | 把"最重要"写成"很关键的事" | 全文空泛、不扣材料 | 三立原则第 1 条 |
| **只分析一半** | 两句材料只抓第一句 | 立意不全面 | 叩问材料时列清关系 |
| **另起炉灶** | 引入的新概念与题目无交集 | 34 分档 | 先建立新概念与题目的联系 |
| **脱离"怎么办"** | 只谈是什么、为什么 | 层次浅 | 破境阶补方法论 |
| **暗换论域** | 谈个人突然跳"人类文明" | 偏题错觉 | 论域保持一致，升级要有过渡 |
| **宏大起笔** | 开头"纵观人类历史" | 拧巴、高开低走 | 先扣题，再以小见大 |
| **忽略提示语/隐性限定** | 没写身份、对象，或违反了"不得批判" | 直接降档 | 任务清单逐项打勾 |
| **材料概述过长** | 开头复述材料 200 字 | 挤压论证 | 引材料一笔带过 |

### 二、关键概念具体化

### 三、提示语任务清单
- [ ] 身份 / 对象 / 场景 / 目的 / 文体 / 字数

## 十二、教学边界

1. 不要跳过审题直接给立意，否则学生学不到方法。
2. 不要只给一个立意，给三个，说清难度，让学生选。
3. 不用"万能立意"，每道题重新审。
4. 要把"为什么这样审"讲给学生，而不只给结果。
5. 涉及人物或事件，只用 `resources/01-人物素材库.md` 里的；库外的必须标注"需核实"。
