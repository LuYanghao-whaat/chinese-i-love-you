# 段落与结构

> 段落乱则全文乱，段落清则全文清。
> 但“清”不等于“套模板”，每一段都应当让文章的认识向前移动一步，而不是换个例子重复同一个判断。

本文件是 Skill 执行提纲生成（M3）、范文写作（M4）、批改评分（M5） 时的结构规范。

> 关于“五句一段法”：它是给不会写段落的学生用的脚手架，能帮人从“观点＋例子＋完”过渡到“有阐释、有分析”。
> 但它不是一类文标准，僵化套用反而会让文章变成“观点＋君不见＋由此可见”的模板（二类文切入分）。
> 成熟的文章用下面第一节的“论证段落闭环”。

---

## 一、论证段落闭环（取代僵化的五句一段）

一个成熟的论证段落，通常包含以下动作（不是必须凑满五句，而是缺哪个补哪个）：

| 动作 | 功能 | 判断标准 |
|---|---|---|
| **① 观点句** | 亮出本段分论点 | 能独立成立、有观点、不是废话 |
| **② 阐释句** | 界定关键词、说清“我指的是什么” | 让读者与你在同一语义平台 |
| **③ 材料句** | 引入事实/数据/案例 | 剪裁精准，只留与论点相关的部分 |
| **④ 分析句** | 把材料与观点**焊接**起来 | **最关键**：指出材料里哪个要素支撑了论点 |
| **⑤ 限定 / 反驳句** | 给观点加条件，或回应可能的反对 | 一类文的分水岭，见 `05` 第八节 |
| **⑥ 回扣句** | 收束本段，扣回分论点或中心论点 | 不能是重复观点句 |

### 与“五句一段法”的关系

五句一段法＝①②③④⑥（观点→阐释→材料→分析→结论），是最小可用骨架。
真正拉开差距的是 ⑤ 限定/反驳句，以及 ④ 分析句里那根箭头够不够结实。

### 段落示例（骨架）

分论点：真正有价值的创造，往往源于对寂寞的深度咀嚼与漫长坚守。

```
（观点）真正有价值的创造，往往源于对寂寞的深度咀嚼与漫长坚守。
（阐释）这意味着创造者需主动远离喧嚣，让思想得以沉淀——这里的“寂寞”不是孤僻，
        而是与研究对象长期独处的专注。
（材料）路遥创作《平凡的世界》的六年里，封闭在陕北窑洞，日复一日面对稿纸。
（分析）试想，倘若他热衷于追逐一时的声名与社交场的繁华，他的精神世界又如何能
        与笔下的黄土高原融为一体？正是这份对寂寞的主动拥抱，才让他得以构建那部
        民族史诗。
（限定/反驳）当然，寂寞本身并不生产价值——若没有对时代的深切关怀，再深的孤寂
        也只是自怜。
（回扣）可见，寂寞不是创造的敌人，而是它的母亲。
```

### 分析句的六种“动作”

分析句不能只写“这体现了 XX 精神”，必须有动作：

- 因果：正是 X，让 Y
- 假设：若没有 X，就没有 Y / 若无 X，何以 Y
- 对比：与其 X，不如 Y
- 追问：为什么 X？因为 Y
- 评价：此等 X，非 Y 所能企及
- 限定：X 成立，但仅当 Z

## 二、全篇结构

### 骨架（约 850–1000 字）

```
开头段（约 120–150 字）
  - 迅速建立“真正的问题”（不是先宏大抒情）
  - 亮中心观点

主体段 1（约 200 字）  分论点 A —— 观境 / 是什么
主体段 2（约 200 字）  分论点 B —— 判境 / 为什么
主体段 3（约 200 字）  分论点 C —— 破境 / 怎么办，或修正/升华

结尾段（约 100 字）
  - 完成最后的修正 / 回扣 / 开放
  - 不是突然“吾辈青年”
```

分论点数量：一般 3 个；也可 4 个（注意字数，单段约 200 字）。

### 分论点的关系（关键是“生长”，不是“凑三个漂亮句”）

> 分论点应从总问题自然生长出多个分问题，而不是先凑三个句子再硬塞素材。

#### 1. 层进式（主流，适合大部分题）
是什么 → 为什么 → 怎么办；或 个体 → 社会 → 时代。

#### 2. 对照式
正面（X 的价值）→ 反面（缺失 X 的危害）→ 综合（如何拿捏 X）。

#### 3. 辩证式（A 与 B 看似矛盾实则统一）
承认 A 的合理性 → 但不能忽略 B → 真正的智慧是把 A 和 B 统一起来。
> 真正的辩证统一，不是“A 重要、B 也重要”，而是研究二者的相互依存与相互转化。

#### 4. 因果式 / 条件式 / 转折式
论点之间也可构成因果链、条件链或转折，不必局限于上面三种。

### 全文逻辑自检

每一段都应让文章的认识向前移动，而不是换例子重复同一个判断。
写完一段，问自己：这段比上一段多说了什么新东西？如果只是换了个素材说同一句话，删掉或改写。

## 三、开头段

开头承担的任务：迅速建立真正的问题 + 亮中心观点。最怕：复述材料过长、只引材料不亮观点、先宏大抒情。

### 可用思路

思路 A：现象 + 张力 + 观点
```
[材料核心一句话]。然而细察之下，[指出矛盾/张力]。
这一张力的背后，[提出值得思考的问题]。在我看来，[中心观点]。
```

思路 B：引言 + 扣题 + 观点
```
[一句紧扣话题的名言/材料句]——[短注]。这正映照了[话题]。[要点]。
在我看来，[中心观点]。
```

思路 C：场景 / 反问切入
```
[一个扣题的反问或场景]？[指向材料]。[回答]。在我看来，[中心观点]。
```

忌：“在当今社会，随着……”这类万能开头；也忌“纵观人类文明史”这类宏大起笔。

---

## 四、结尾段

结尾的任务：完成最后的修正 / 回扣 / 开放。不是“突然吾辈青年”，也不是重复中心观点。

### 三种收法

1. 修正式：收回开头时那个粗糙的判断，给出更准确的新版本。
   > “最重要”不是僵化的标签，而是流动的智慧；不应是稀缺的焦虑，而应是行动的号角。
2. 回扣式：回扣开头意象/问题，形成闭环。
3. 开放式：把问题再往前推一步，留下余味（不强行给结论）。

### 关于“引一句 + 呼吁青年”

这是可选项，不是必选项。新高考越来越警惕“结尾升华 + 吾辈青年”的套路。
- 要引：就引一句真正服务观点的，别为引而引。
- 要呼吁：就落到具体的动作主体（见 `05` 第九节），别喊空口号。

## 五、节点语言（让文脉清晰）

节点语言是标记逻辑走向的词。一篇好议论文里随处可见，让阅卷老师一眼抓到思路。

| 功能 | 常用节点词 |
|---|---|
| **推进展开** | 由此我想、在我看来、进一步而言、更值得思考的是 |
| **深入追问** | 更主要的问题是、其实、可见、值得注意的是、归根到底 |
| **转折反问** | 真的是这样吗？但从来如此便对吗？遗憾的是、然而、可是 |
| **因果分析** | 之所以…是因为、究其缘由、根本在于 |
| **假设分析** | 倘若…又怎能、若无…何以 |
| **条件分析** | 只有…才能、唯有…方能、除非…否则 |
| **限定修正** | 当然、诚然…但、这一判断成立的前提是 |
| **提出建议** | 我们建议、我想、作为青年 |
| **收束结论** | 可见、由此可见、归根结底 |

### 使用原则

1. 转折点必须用节点词，别让阅卷老师猜你在转折。
2. 同一个节点词不要用超过两次。
3. 节点词服务于逻辑，不是装饰，别为了“显得有逻辑”而硬加。

## 六、段落与结构检查清单

> 批改时的用法：这是改进建议清单，不是扣分表。
> 尤其“素材”“节点词数量”“引一句诗词”这几项，缺失不构成硬伤，更不据此压等级。
> 批改先通读、先定等级，再用清单里的条目提建议。

### 开头段
- [ ] 是否迅速建立了真正的问题（而非宏大抒情）？
- [ ] 是否亮了中心观点？
- [ ] 标题是否观点式 / 有张力，不是“论 XXX”式？

### 主体段
- [ ] 每段是否让认识向前移动（而非换例子重复）？
- [ ] 观点句 → 分析句之间，箭头补齐了吗？
- [ ] 是否至少有一段做了限定 / 反驳（辩证）？
- [ ] 分论点之间关系清晰（层进 / 对照 / 辩证 / 因果 / 条件）？
- [ ] 若用了素材：素材是否扣观点、有没有被分析？（没素材但说理充分，同样成立）

### 结尾段
- [ ] 是否完成了修正 / 回扣 / 开放（而非突然升华）？

### 全篇
- [ ] 论域是否一致（没有暗中换赛道）？
- [ ] 字数 850–1000 字？
- [ ] 有没有一处真正的思辨（不是“A 好 B 坏”）？

## 七、特别提醒

1. 标题

对仗/观点式/化用当然好，但不要为对仗牺牲准确。标题的核心是有观点、有张力。
- 好的方向：`守“爱”为灯，辨我为人`、`在流变中守护永恒`、`灰何时为黑，何时为白`
- 忌：`论选择`、`谈热爱`、`关于“最重要”的思考`、`浅谈 XXX`

2. 主体段首句要敢“亮大话”

段首甩出一句能独立成立、有观点、有文采的句子。别藏着掖着。

3. 素材不要只用一个（但这是“更上一层”，不是及格线）

会写素材的学生，每段可用 2–3 个素材构成排比，形成气势。
> 注意：若学生走的是思辨 / 说理路线，一个素材都不用也完全成立，不要拿这条去否定文章。

4. 分析句必须有动作

见第一节“分析句的六种动作”。
