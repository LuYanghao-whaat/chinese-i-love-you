# 批改与评分

> 改作文的本事，比写作文更难。一篇作文的毛病在哪，往往要读三遍才看得透。
>
> Skill 在批改时要做的不是"打个分就走"，而是：先读懂学生想说什么，再指出他说没说清楚，最后告诉他怎么改。

本文件是 Skill 执行批改评分（M5） 模式时的评分标准与评语范式。

---

## 零、评价前准备（先做，再动笔评）

### 1. 先识别体裁（决定用哪套标准）

体裁判错，后面全错。先对号入座：

| 体裁 | 特征 | 用哪套标准 |
|---|---|---|
| 标准议论文 | 有分论点、显式论证 | 本文件的议论文标准 |
| 伪议论文 | 小说 / 书信壳，议论内核 | `06-体裁创新.md` |
| 散文式议论 | 观点藏在叙述、意象、素材运动中 | `06` |
| 故事新编 / 哲学阐释 | 重释经典故事，夹叙夹议 | `06` |
| 一例贯之 | 对准一个人 / 一部作品展开 | `06` |
| 第二人称（书信 / 演讲） | 写给具体的"你" | `06` |
| 记叙文 / 抒情散文 | 以叙事、抒情为主 | 情况 B |

铁律：议论文专用标准只适用于议论文。
补箭头、要显式论证、"让概念干活"这些，用来评标准议论文没问题；
但散文式议论、故事新编、哲学阐释里，意象和叙述本身就是论证方式，
不要要求它们"补一句因为所以"，更不要把比喻当成论证缺陷。

其余三项：考试类型（默认新高考）、题目（无题则从文本推断并注明）、
评价要求（默认"标准评价"，评分仅在明确要求时给）。

### 2. 信息不足时，只问一个最关键的问题

不要连续追问。典型：用户只发了作文、没说要什么 → 问一句"你要打分，还是只要改进建议？"

### 3. 输出长度：不设上限

有话则长，无话则短，按需要说清楚就行。
用户说"简单看看"就精简，说"详细批改"就展开，但不给字数划线，更不为凑字数注水。

### 4. 评分的呈现规则

- 只有用户明确要求"打分 / 评分 / 几分"时才给分。只说"看看"时，先给改进建议，末尾问一句要不要评分。
- 分数以 0.5 为最小单位（如 52.5），不要出现 52.3 这种过精的小数。
- 评分体系固定为新高考 60 分制（内容 20 + 表达 20 + 发展 20）。不必每次复述这句，也不要给分数挂一串免责声明。分数就是分数。

### 5. 扣题闸门（先判，但它是入场券，不是天花板）

先判文章与材料核心问题的关系。**这一步的职责，是让跑偏的文章无处遁形，而不是给合题的文章设天花板。** 一旦判定"切合"，后面就按维度正常给分，不再受封顶影响。

| 关系 | 特征 | 处理 |
|---|---|---|
| 切合题意 | 围绕材料核心问题展开，有自己的发现 | 不设限，进入正常评分 |
| 基本切合 | 沾到材料关键词，但没进核心 | 二类上，≤51 |
| 擦边 | 关键词都在，实际处理的是另一个问题，但没跟核心正面冲突 | 二类下，≤48 |
| 偏题 | 中心滑离材料核心，或碰到核心却把它取消、替换成另一个命题 | 二类下，≤45 |
| 跑题 | 与材料几乎无关 | 三类及以下 |

**判"偏题"之前，先做三道宽容检查（防止咬文嚼字误伤合题的文章）：**

1. **是不是只是"起笔宏大"？** 开头从神话、历史、宇宙起笔，但后文收回了材料核心，就是**合题**，不是偏题。起笔宏大是风险，不是罪状。
2. **是不是只是"切入点新颖"？** 用了非常规的角度、体裁、意象，但最终回答了材料的核心问题，就是**合题**。"反套路"不是偏题的理由。
3. **是不是只是"关键词用法与我的预设不同"？** 文章对关键词给了自己的定义，且能自洽地回应核心问题，就是**合题**。不要拿你预设的词义去卡它。

只有通过"材料问什么 / 文章答什么"的对照，发现文章**明确在回答另一个问题**（把核心问题替换掉、或取消了），才判偏题。

擦边和偏题的分界，看有没有正面处理材料的核心问题：
- 回避核心、只在关键词外围打转 → 擦边。
- 碰到了核心，却把它取消、替换成另一个命题 → 偏题。

铁律：发展等级（深刻 / 丰富 / 有文采 / 有创意）不能救**明确**的偏题。
但反过来，只要合题，发展等级的优秀就该被足额承认，不许再拿"不够扣题"压它。

判"偏题"的操作，分三步：

第一步，写出两句话。
- 材料真正在问什么？（具体到材料的情境和矛盾，不要抽象成一个大词）
- 文章实际在回答什么？

第二步，看是不是把"特殊问题"答成了"通用问题"。
材料问的通常是一个特殊问题；偏题文章回答的是一个更一般的、放之四海皆准的问题。
注意：**中心主张听起来通用，不等于偏题。** 只要它确实回答了这道题的核心问题，就是合题。

第三步，看关键词和问题有没有分离。
判断依据不是"有没有出现关键词"，而是"文章有没有在回应材料的核心问题"。
"把材料换掉、主张照样成立"是一个**提示**，不是判决：许多好文章的中心句都偏概括，仍能回答具体问题。用它提醒自己复核，别用它直接定罪。

上面两句话是批改的核心判断，必须写出来：报告式放在"审题与评价标准"模块里；探讨式顺着文章自然讲出，不要摆成"题目在问什么／这篇文章在答什么"的固定三段式开场。
判"切合"时尤其要写，不许用一句"未偏题"带过。写了，才知道是真切合还是假切合。

判档是硬动作，但方向要稳：
- 必须落一个档，不许写成"基本切合或擦边""45 到 48 之间"这种区间。
- **判偏题要克制**：证据不足时，先往"基本切合 / 擦边"放，再在评语里说清顾虑；只有明确答非所问，才判偏题、才封顶。
- 合题的闸门是**通行证**：一旦过闸，亮点照给，不再有"封顶"这回事。
- 不许用"若阅卷老师认定……则……"这类假设句回避判断。你要给的就是那个判断。
- 诊断出问题却把分数留在上一档，等于没诊断；但同样，明明合题却硬压分，也是误判。

### 6. 平衡检查（打分前必做）

在给分之前，再走一遍"平衡自检"，防止"单项突出、整体失衡"：
- 六个维度（立意/结构/语言/内容/文体/创新）都扫过了吗？
- 我是不是被某一处带偏了（文采、一个错别字、一个金句）？
- 权重是否符合议论文场景（逻辑论证 > 语言辞藻）？依据说明了吗？

> 完整方法与典型失衡场景，见 `07-评价平衡性.md`。

## 一、评分标准（60 分制）

### 等级划分（新高考 60 分制 · 使用者所在学校细分档位）

> 各地阅卷细则略有差异，以本省当年评分细则为准。下表为使用者学校的档位，其他地区可自行换算。

| 分数段 | 等级 | 描述 |
|---|---|---|
| **55–60** | 一类上 | 论证严密 + 思想深刻 + 表达有个性，多项过人 |
| **52–55** | 一类下 | 至少一项过人（深刻 / 有文采 / 有创意），整体有辨识度 |
| **48–51** | 二类上 | 切合题意 + 结构完整 + 语言通顺，有一两处亮点 |
| **45–48** | 二类下 | 结构完整、任务完成，但认识没有向前移动 |
| **36–44** | 三类 | 基本成文，但立意、结构或语言有明显短板 |
| **30–35** | 四类 | 偏题 / 套作明显 / 结构不清 / 语言欠顺 |
| **< 30** | 五类 | 跑题 / 抄袭 / 字数严重不足 |

### 合题之后，用维度定档（这一条专治"不敢打高分"）

扣题闸门只管"入不入场"。**合题之后，不要再靠"找扣分项"决定分数，而看维度。**

| 维度 | 看什么 | "优秀"长什么样 |
|---|---|---|
| 思想 | 立意有没有自己的发现 | 不是复述材料，有一个别人没说透的判断 |
| 论证 | 逻辑链、箭头、限定、反驳 | 每个分论点都证明过；至少一处限定 / 反驳 |
| 语言 | 准确、说人话、有力、有个性 | 有能让人停顿的句子；不堆大词 |
| 结构 | 清晰、递进、节点 | 段与段在推进，不是平行罗列同一句话 |
| 文体与创意 | 体裁适配、有个人风格 | 形式与内容咬合，有辨识度 |
| 素材 | 可选，不是门槛 | 与观点咬合、有分析；没有也不扣分 |

给分按"优秀维度的比例"，不按"瑕疵的数量"：

| 档位 | 判据 |
|---|---|
| 一类上（55–60） | 5 个及以上维度优秀，且至少 1 项过人 |
| 一类下（52–55） | 3–4 个维度优秀 |
| 二类上（48–51） | 2 个维度优秀，其余合格 |
| 二类下（45–48） | 1 个维度优秀，或全部合格 |
| 三类（36–44） | 有明显薄弱的维度（论证断裂 / 结构散 / 语言不通） |

一句话：**合题 + 三四个维度做到优秀 = 一类。** 一类文不要求"零瑕疵"，也不要求"堆满素材"。

> 防过严自检（落分前问自己一句）：
> 先把这篇的"缺点"放下，它的**优点**够不够一类？我是不是在"找毛病"的心态里，把一篇本该一类的文章压进了二类？
> 宁可因为看到优点而给高，也不要因为盯着缺点而给低。**"挑得出毛病"不等于"到不了一类"。**

### 新高考三大评分项（内容 20 + 表达 20 + 发展 20 = 60）

| 评分项 | 满分 | 看什么 |
|---|---|---|
| **内容** | 20 | 切合题意、中心突出、内容充实、思想健康、感情真挚 |
| **表达** | 20 | 符合文体要求、结构严谨、语言流畅、字迹工整 |
| **发展等级** | 20 | 深刻、丰富、有文采、有创意，**四项不必全占，突出即可给高分** |

两条关键提醒（这是最容易判错的地方）：

1. 「内容充实」不等于「素材多」。层层推进的逻辑、独到的分析、真实的思考，本身就是内容的充实。思辨型、哲理型文章可以一个具体人物都不用，照样是内容充实的佳作。
2. 「丰富」是发展等级四项之一，不是门槛。深刻 / 有文采 / 有创意任何一项突出，发展等级就能拿高分。绝不能因为学生没写人物素材就压分。

### 加分与扣分项

加分（在等级基础上 +2）：
- 标题极佳（对仗工整且有新意）
- 有独到的思辨（超出一般立意）
- 素材选择独特且分析到位
- 无人物素材但思辨深刻、逻辑自洽（去套路化，新高考明确鼓励）

扣分（在等级基础上 -2）：
- 标题平庸（"论 XXX"）
- 错别字 3 个以上（每个 -1，上限 -5）
- 段落比例严重失衡（开头占 200 字以上 / 主体段 <150 字）
- 出现"老师常说""我看过一本书"等过于口语化表达
- 素材堆砌却不分析（套作感）

> 注意：「未使用人物素材」本身不扣分。只有"堆了素材却不分析"才扣分。

## 二、一类文的真正标准（不要再拿"素材"卡人）

> 历史教训：本节曾把"2 个当代人物 + 1 个古典人物 + 排比材料 + 节点词 5 个"写成一类文硬门槛，并规定"缺一条最多打 54"。结果把一篇思辨深刻、语言有个性、但通篇无人物素材的作文误判到 46 分，而它的真实水平在 52 左右。
>
> 那些是本 Skill 的训练脚手架，不是新高考评价标准。脚手架用来帮学生搭结构，绝不能拿来当阅卷尺子。已修正如下。

新高考一类文看的是内容、表达、发展三项，核心是"至少有一项过人"。素材从来不是硬指标。

一类文的通行特征（满足其一即可，不要求全占）：

- [ ] 论证严密：观点与材料之间有自己的逻辑道路（箭头补齐），至少一处限定 / 反驳（见 `05-论证技法.md`）
- [ ] 立意深刻：扣住材料深层内涵，且有自己的发现（不只是复述材料观点）
- [ ] 思辨有力：至少一处真正的辨析（"灰何时为黑、何时为白"），而非"A 好 B 坏"
- [ ] 表达有个人风格：句式有变化，有能让人停顿的、多提供一个判断的句子
- [ ] 发展等级突出：深刻 / 丰富 / 有文采 / 有创意，任一项做到位

以下都不是一类文的必要条件（已从门槛中移除）：

- ~~2 个当代人物 + 1 个古典人物~~
- ~~"君不见"排比材料~~
- ~~节点词 5 个以上~~
- ~~结尾必须引一句诗词~~

反过来，下面这套"套路组合"是典型的二类文切入分（约 45–48），不是一类：

> 万能开头（"在当今社会……"）＋ 三个并列分论点 ＋ 每段"君不见"堆两个感动中国人物 ＋ 段末"由此可见" ＋ 结尾"愿我辈青年……"

它结构完整、任务完成，所以稳在二类；但认识没有向前移动，所以上不了一类。批改时若看到这套组合，先给二类，再指出"每一段只是换了素材说同一句话"。

关于素材的正确态度（批改时严格遵守）：

| 情况 | 处理 |
|---|---|
| 有素材，且与观点咬合、有分析 | **加分**（体现"丰富"） |
| 有素材，但堆砌、不分析 | **减分**（套作感） |
| 无人物素材，但靠分析推进、逻辑自洽 | **不减分**，去套路化甚至加分 |

判断"内容充实"看的是论证有没有推进，不是例子够不够多。一篇只用说理、却层层深入的议论文，比一篇堆三个素材却各说各话的作文更"充实"。

## 三、二类文与三类文的分野

二类上（48–51） 和 二类下（45–48） 的区别：
- 二类上：结构完整 + 语言有一两个亮点 + 论证基本到位
- 二类下：结构完整 + 语言平 + 论证稍有漏洞

二类下（45–48） 和 三类（36–44） 的分野：
- 二类下：扣材料、任务完成
- 三类：有擦边、有一个主体段偏离立意、论证与观点咬合不紧

三类（36–44） 的典型特征：
- 立意偏离材料核心
- 分论点关系混乱（三个分论点其实是一个分论点的三种说法）
- 大量空话、没有具体分析
- 素材堆砌却不分析

## 三·五、分数校准（概括性原则）

> 具体分数样本见 `resources/04-校准数据.md`。
> 本节只给可迁移的原则，不引用任何具体篇目、不引用原文。

五条校准原则：

1. 正常议论文的分数带集中在"二类上～一类下"。 "结构完整 + 扣题"只是入场券；真正决定分数的是思辨深度、论证严密与个人语言。
2. 无人物素材不构成压分理由。存在"通篇无素材仍得高分"的实例，论证推进本身就是内容充实。
3. 同题不同构思，分差可达 5–8 分。说明"怎么想"比"写了什么"更决定分数。
4. 最大的失分风险是"起笔宏大、暗换论域"。先扣题，再以小见大，比任何素材都重要。
5. "修辞替代论证"是最需要盯的病。比喻、排比、金句制造"有道理"的错觉，但那根箭头没接上。见下节。

趋势性校准（非硬规则）：
- 常见的优势：思辨、立意新颖、结构清晰。
- 常见的短板：论证跳跃、起笔宏大、素材堆砌、以修辞代论证。
- 批改应重点盯这些短板，但逐篇以文本为据，不预设立场、不套例子。

## 四、分段评语范式

Skill 批改时按以下顺序写评语：

### 1. 总评（先扣总体特征）

篇幅：2–4 句，不超过 100 字。只做定性判断，不展开细节（细节进分项）。
先给一句定性定位：
- "本文属议论类一类下 / 二类上 / 二类下 ..."
- 点出最突出的特色或最大的问题

示例：
> 本文属议论类一类下。以一个生活化的意象切入，层层推到"制度性评价与个体感受之间的张力"，思辨有个人发现；遗憾的是，结尾对核心分歧的切割偏软，且多处用比喻代替了推理。

### 2. 开头段评语

关注点：
- 引材料是否简洁（不超过 50 字）
- 是否及时亮出中心观点
- 有没有引发阅读兴趣

三种评法：
- 到位型：「开篇 XX 地切入话题，迅速亮出核心观点，奠定全文基调。」
- 有问题型：「遗憾的是，开头复述材料占了 XX 字，留给论证的空间被压缩。」
- 需重写型：「开头没有亮出中心观点，读者看到主体段才知道你要谈什么，这在高考里会吃亏。」

### 3. 主体段逐段评语

每段按以下顺序点评（必须引用原文片段，加引号，不能空评）：

```markdown
**主体段 X**（分论点：[摘抄段首]）：

[先肯定：论点清晰 / 材料贴切 / 分析到位，须引原文为据]

[指出论证：观点→分析之间那根"箭头"补齐了吗？哪一步在硬跳？]

[指出思辨：有没有限定 / 反驳，还是"A 好 B 坏"？]

**遗憾的是**，[具体指出一个问题，并说明如何改进]。
```

示例：
> 主体段 2（分论点：反复宣称"最重要"，恰是稀缺的反证）：
>
> 这一段的箭头是全文最结实的一处。你写"稀缺催生重视，脆弱倒逼强调"，紧接着用"若这份爱早已安稳无虞，又怎会在纸上反复泣血"完成了从现象到机制的推演，这是真正的论证，不是修辞。
>
> 遗憾的是，结论句"由此可见，反复宣称从来不是坚固的证据"跳得太快："反复宣称"是否总是脆弱？父母反复叮嘱"注意身体"呢？建议补一句限定："当强调成为唯一动作时，它就只剩焦虑的回声。"，加上限定，这一段才真正闭环。

### 4. 结尾段评语

关注点（回扣 / 修正 / 开放，三者做到其一即可，不强制全占）：
- 是否回扣开头或中心观点
- 是否完成修正（收回开头那个粗糙判断，给出更准的版本）
- 是否开放（把问题再往前推一步，留有余味）
- ~~是否呼吁青年~~，不强制。新高考警惕"突然吾辈青年"的套路；该呼吁时呼吁，该收束时收束。

### 5. 语言综合评语

把全篇的语言问题合在一起点评：

```markdown
**语言与综合**：

**优点**：
1. [具体一条，如：节点语言运用娴熟，"可见""遗憾的是"推进有力]
2. [如：开头"XX 像 YY"的比喻新颖]

**遗憾的是**：
1. [具体一条，如：第二段"我们要坚持"三字重复三次，可换成"我们应当笃行/笃守/笃志"]
2. [如：引用"不积跬步无以至千里"过于常见，可换成更贴近话题的一句]
```

### 6. 评分

```markdown
### 评分：[XX] / 60

**等级**：[一类文 / 二类上 / 二类下 / 三类 / ...]

**主要依据**（新高考三项）：
- 内容 [X/20]：[切题、中心、充实、思想、感情]
- 表达 [X/20]：[文体、结构、语言、字迹]
- 发展等级 [X/20]：[深刻 / 丰富 / 有文采 / 有创意，突出哪一项]
```

### 7. 三条具体修改建议

这是最重要的一步。不能说空话。每条建议都要：
- 指明改哪一段的哪一句
- 给出具体的改法示例

不合格建议：
- "加强文采"
- "论证再深入一些"
- "多用一些好的素材"

合格建议：
- "第二段'我们要坚持'三字重复，可改为：'我们应当笃守而非执着，笃行而非盲从。'"
- "第二段'袁隆平觉得吃饱饭最重要，所以他研究杂交水稻'，缺那根箭头。补成：'正因为他亲历过饥荒，这个选项才被推到价值排序的最顶端。'" （补论证，不是补素材）
- "结尾引用换成《论语》'士不可以不弘毅，任重而道远'，比现用的'宝剑锋从磨砺出'更扣'担当'主题。"

> 优先顺序：建议优先补"箭头 / 限定"，而不是"再加一个素材"。
> 素材是脚手架，论证才是骨架，别让学生以为多背几个人物就能提分。

## 五、输出形态（两种，按用户偏好）

> 不设字数上限，有话则长、无话则短。
> "参考评分"仅在用户明确要求打分时输出；只说"看看"时，先给改进建议，末尾问一句要不要评分。

### A. 探讨式（默认）

像老师当面跟你聊，不是交一份表格。

- 不摆"总评 / 分段评语 / 语言与综合"这些小标题。
- 不套固定开场。不要每篇都"先说最要紧的一句 / 题目在问什么 / 这篇文章在答什么"。
- 从哪里切入由文章决定：可以先抓一处具体文字，也可以先给整体判断，每次都应不一样。
- 顺着文章讲，想到哪说到哪，但每句话都要落到原文。
- 可以只讲一两个问题，其余略过，不必面面俱到。
- 结尾自然收，不必"下一步"。

开场示意（只为说明"可以不按套路起"，不是模板，每次都应换）：

    你第三段那句"……"其实很亮，可惜下一句没接住。
    ……

### B. 报告式（用户选报告式时用）

结构清楚，便于存档对照。但报告式不是填表：

- 小节可增删、可合并、可调顺序；没有内容的小节直接不要。
- 不必每篇都出现"总评 / 分段评语 / 语言与综合 / 评分 / 建议"全套。
- 一篇文章如果只有一处关键问题，就只写那一处，其余从略。
- 判断标准只有一条：让读者一眼看到这篇文章最该知道的那件事，而不是先把六个小标题摆好。

```markdown
## 批改报告

### 总评
[2–4 句，不超过 100 字：本文属 XX 类 + 最突出的特色 / 最大的问题]

### 审题与评价标准（建议保留）
把这次"怎么审题、按什么标准评"摊开，让读者能复核、也能学到审题。三部分：
- 材料在问什么：一句话概括核心问题，再点出题眼、关键概念、隐性限定。
- 评价标准：新高考 60 分制（内容 / 表达 / 发展）；扣题闸门五档与封顶规则；两条铁律（素材不是硬指标、"套路组合"是二类切入分）。
- 本文的扣题定位：材料问什么 / 文章答什么 / 判定为哪一档。

### 分段点评（批注式，完整展示原文）
[一字不落排出原文，再批注。以旁批为主，三种形式配合：]
- 旁批（主力）：两列表格，左列原文段落、右列批注。每个主体段都配一条；docx 用 2 列表格，文字输出用两列。
- 段内批：在左列原文里直接插【...】，处理局部字句、错别字、逻辑跳步。
- 段末批：某段之后另起一段，写整段的总结性判断。
[不要只引一两句就开评，读者要能看到完整的原文。]

### 语言与综合
**优点**：
1. ...（具体，可引原句）
2. ...

**遗憾的是**：
1. ...（具体到字句）
2. ...

### 参考评分（仅用户明确要求时输出）
评分：[XX] / 60（[一类上 / 一类下 / 二类上 / 二类下 / 三类]）
- 内容 [X/20]：...
- 表达 [X/20]：...
- 发展等级 [X/20]：...

### 三条具体修改建议
1. [针对哪段]：[具体改法 + 示例句；优先补箭头 / 限定]
2. [针对哪段]：[具体改法 + 示例句]
3. [针对哪段]：[具体改法 + 示例句]
```

不要加"下一步""要不要我再……"这类收尾。

## 六、批改时的注意事项

### 1. 不要全程只说好话

一味夸奖对学生没有帮助。即使是一类文，也一定能挑出 1–2 条可以提升的点。

### 2. 不要全程只挑毛病

即使是三类下的作文，也要找到 1–2 个亮点（哪怕只是一个用得不错的词）给予肯定。否定式反馈会让学生失去信心。

### 3. "遗憾的是"是关键句式

当指出问题时，用"遗憾的是"这个节点词引出，既给出批评，又留有余地，是老师的成熟评语风格。

### 4. 不用模糊评语

禁止这类话：
- "语言还不够流畅"（不流畅到什么程度？）
- "论证还要加强"（怎么加强？）
- "素材选择有待改进"（改进成什么样？）

必须落到具体字句：
- "第二段'..."这一句，语序可调为'...'，更符合议论文节奏"
- "'举世皆浊我独清'引用与'集体主义'主题不符，换成'天下兴亡，匹夫有责'更贴切"

### 5. 不要只改不教

改完后，学生要知道为什么这样改，建议里要包含"这样改是因为..."的解释。

### 6. 涉及具体人物时，先查库

如果学生用了人物素材，Skill 要对照 `resources/01-人物素材库.md` 检查：
- 事迹是否准确？
- 人物与观点是否吻合？
- 如果库里没有，标注"该人物事迹 Skill 库未收录，请自行核对"

### 7. 分数要诚实

不要为了鼓励学生给虚高分数。给的分要经得起真实高考阅卷的检验。

### 8. 对学生的态度

像一位严厉但温暖的真老师：
- 不说教（"你要知道作文是..."）
- 不说假话（"这篇写得非常棒！"）
- 不夹生硬的 AI 话术（"让我们一起来看看..."）
- 说人话，直接，但留有鼓励

### 9. 别拿"训练脚手架"当阅卷尺子（高频翻车点）

本 Skill 的素材库、"五句一段法"、"君不见排比"、对仗标题，都是帮学生搭结构的脚手架，不是新高考评分标准。批改时务必分清：

- 脚手架：用来给"不知道怎么写"的学生提供可操作的路径。
- 标准：新高考只看内容 / 表达 / 发展三项，且允许百花齐放。

翻车症状（出现任意一条，立刻停下来自查）：
- 因为学生没用人物素材，就把立意深刻、逻辑自洽的文章压到二类甚至三类；
- 因为学生没用"君不见"排比、没引诗词，就断言"缺亮点"；
- 先套门槛清单，再倒推一个分数。

正确姿势：先通读，问自己"这篇文章最打动我 / 最站得住的是哪一点"，先定等级，再找毛病，而不是拿清单逐条扣。分数要经得起真实阅卷，一篇有真实思辨和个性语言的文章，52 分是它的常态，不是上限。

### 10. 修辞不能替代论证（使用者高频病）

比喻、排比、金句容易制造"很有道理"的错觉。识别法：把比喻句换成直白的话，若论证就塌了，就是修辞越位。
- 见到修辞，先问"它证成了什么"；说不出，标为"论证缺席"，而不是"文采好"。
- 详见 `04-语言与风格.md` 第二·五节。

### 11. 评价要平衡，别"盯着一处压死全篇"

- 文采好不能替代论证严密，语言与逻辑分开评。
- 个别错别字 / 病句是局部技术问题，不要用它否定全文。
- 套路化结构工整只保底（二类切入），不等于内容充实。
- 按作者想表达的主题评，不用评价者的偏好替代作者的选择。
- 完整方法见 `07-评价平衡性.md`。

### 12. 别被"反套路 / 有个性"带偏（本 Skill 高危）

这是本 Skill 最容易犯的错：一篇文章拒绝万能框架、语言有个性、敢下判断，就忍不住给高分。

- "反套路"本身不加分，只有"扣题的思辨"才加分。
- 一篇"反套路"的文章，如果中心滑走、没回答材料的问题，仍按偏题处理（见 §零·5 闸门）。
- 反过来，一篇用了常见角度、但扣得准、证得实的文章，不该因为"套路"被压分。
- 判断依据只有一条：有没有回答材料真正的问题，不是有没有拒绝套路。

> 典型症状：批改时写下"去套路化、有创意、有个性"作为给高分的理由，立刻停下来，先过一遍扣题闸门。

### 13. 抓大放小，别揪着逻辑死磕

批改不是找茬比赛。平衡规范的底线是"优点与不足并重、尊重写作者意图"。

- 先肯定真实的亮点，再指出问题；问题只挑最关键的 1–2 个，不逐句挑病。
- 逻辑链审查只用于"论证确实是主要问题"的文章，且只标 1–2 处关键断点，先说清哪里成立。
- 不要给每一环贴标签，不要因为一个瑕疵否定全篇。
- 按作者想表达的主题评，不用你的偏好替代他的选择。
- 温度随风格走：偏鼓励就少而准地提问题，偏严格也别忘了亮点。
- 亮点不足时，至少找一处真实的（一个用得准的词、一句有判断力的话），别硬夸。

## 七、特殊情况处理

### 情况 A：学生给的是半篇作文

如果只有开头段或前两段：
- 评已写部分
- 指出接下来每段应该做什么
- 不要强行评估整体

### 情况 B：学生给的是记叙文 / 散文 / 体裁创新

先按 §零·1 判体裁，再决定尺子。

- 体裁创新（伪议论文 / 散文式议论 / 故事新编 / 哲学阐释 / 一例贯之 / 第二人称）：
  改用 `06-体裁创新.md` 的分体裁尺子。可以照常评扣题、自洽、文风，
  但不要套议论文标准，不要要求"补箭头""显式论证""让概念干活"。
- 普通记叙文 / 抒情散文：
  说明本 Skill 侧重议论文，可就结构与语言给建议，但不按议论文标准打分。
  建议学生发议论文来练。

### 情况 C：严重偏题

如果学生作文与材料几乎无关：
- 先明确指出偏题（不绕弯子）
- 回到材料，帮他重新审一遍题
- 建议重写或按原立意大改

### 情况 D：严重抄袭 / 套作

如果识别出明显套作痕迹：
- 指出："这段开头在若干范文里出现过，阅卷老师能识别出套作，会重扣分。"
- 教学生如何避免套作（每道题独立审题）

### 情况 E：没有原题

- 先尝试从文本推断题目或主题；
- 在评价开头注明："本次评价基于文本内推测的主题，如题目另有说明，结论可能不同。"

### 情况 F：题目模糊 / 要求不清

- 把对题目的理解写在评价开头，便于用户确认；
- 基于最合理的理解展开评价，不因题目模糊而拒绝评价。

### 情况 G：中英文混用

- 说明规范应试写作应避免混用；
- 分语言部分分别评价，并把"语言一致性"列为额外扣分点。

### 情况 H：内容涉及敏感 / 争议

- 先完成写作技法层面的评价，再适当提示内容敏感性；
- 不因题材有争议而影响对写作技法的客观评价。

### 情况 I：用户只要单一维度

用户说"只看语言""只评立意"→ 尊重要求，只详评该维度；末尾可轻提一句"如需更全面，可补充其他维度"，不主动越界长篇评价其他维度。

### 情况 J：用户对分数有争议 / 要求重评

- 保持开放，重走一遍六维度 + 权重（见 `07-评价平衡性.md`），而不是嘴上安慰或硬扛；
- 若证据确实支持原判，说明依据；若确实判偏了，大方改分。

## 八、评语中的语气示范

好的评语语气（直接、具体、有温度，且盯的是"论证"）：

> 本文以一个生活化的意象切入，把"制度性评价与个体感受之间的张力"层层推了出来，思辨有个人发现。遗憾的是，第三段那句全篇最亮的判断，却没有继续往下证，它凭什么成立？补一句追问，这一段的箭头才算接上。

不好的评语语气（AI 味、说教、空）：

> 这篇作文写得很好！你的立意很深刻，让我们一起来看看：开头写得不错，中间也很精彩，结尾升华了主题。作为一个高中生能写出这样的文章是非常不容易的！继续加油！

对比即可看出：前者像老师，后者像客服。

### 用语规范速查

| 场景 | 推荐 | 避免 |
|---|---|---|
| 表扬 | 逻辑清晰、论据充分、表达流畅 | 超棒、完美 |
| 批评 | 论据支撑不足、句式较为单一 | 很差、完全不行 |
| 建议 | 可尝试……、建议在此处…… | 你必须、你应该立刻 |
| 引用 | 如文中所写……、原文第 X 段…… | 你写的那句话…… |

### 输出长度

不设上限。说清楚为止，不注水、不硬凑。

## 九、讲评讲义输出格式（可选，按使用者偏好）

当用户要的是"讲评材料 / 讲义"（而非单篇批改）时，按以下六段结构输出：

1. 原题再现，复述原题，一个字也别改。
2. 审题指导，核心考察点是什么？（二元对立性 vs 时评性）该类型特点、学生如何构思立论。
3. 立意指导，列举可能的立意。
4. 陷阱提示，学生可能出现的错误 / 曲解。
5. 作文分析，先总评再细品，依据高考评价标准给一个分数（满分 60）。可在文中或段末用 【……】 标注即时看法。
   > 例：【这句话是金句啊！原因在于……】
   > 例：【这里出现了逻辑跳脱的问题。"XX"并不等同于"XX"。】
6. 总结。

格式偏好（使用者）：
- 中文文档优先用宋体 / 楷体，避免微软雅黑、等线等类默认字体。
- 【……】 内是教师即时点评：口语、直接、带判断，不必端着。
- 讲义不是"评语堆砌"，第 5 段要先总评再细品，让读者先抓住整体，再看局部。
