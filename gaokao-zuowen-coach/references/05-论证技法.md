# 论证技法

> 素材不是论证。
> 例子和结论之间，必须有一条由作者亲手铺出的逻辑道路；这条路要最短、最稳，每一块板石都是一个判断。
> 大多数"有素材却没分"的作文，缺的从来不是例子，而是这条路上的一根箭头。

本文件是 Skill 的核心方法论，执行 M2 立意打磨 / M3 提纲 / M4 范文 / M5 批改 时按需调用。
它对应新高考评价里的发展等级（深刻、丰富、有文采、有创意），是 52 分以上真正的分水岭。

---

## 零、总纲：议论文的三个问题

一篇议论文，本质上是在回答三个问题：

1. 对文题，你有什么看法？立论（要新颖、有创造）
2. 你为什么这样看？论证（要严谨、准确）
3. 你想做些什么？方法论（要落地、可执行）

「三境七论」（见 `01-核心审题法.md`）解决第 1 个问题；本文件解决第 2 个问题。
第 3 个问题单独见本文件第九节。

学生写作的三个阶段（批改时先定位学生在哪一阶段）：

| 阶段 | 表现 | 病灶 |
|---|---|---|
| 初期 | 有素材就一股脑堆上，加几句"显而易见""由此可见" | **素材≠论证** |
| 中期 | 以论证为主，素材辅助，方向对了 | **箭头有漏洞** |
| 成熟 | 论证严密、有限定、能自我修正 | 打磨思想与语言 |

## 一、思维链与隐含前提

### 1. 思维链

在素材与结论之间铺一条完整、尽量短而可靠的路。

- 先铺中间的路，再向两侧延伸；
- 路不能铺歪（方向反），也不能铺太长（啰嗦）；
- 每一段都要问：这一步凭什么成立？

病句示例：
> 王安石感叹"尽吾志而不能至者，可以无悔也"，这证明过程比结果更重要。

问题：从"尽志无悔"到"过程比结果重要"，中间缺了好几块板石。至少要有："他把过程的完成本身视为一种价值"→"这种价值不依赖于结果是否达成"→"因此过程具有独立于结果的意义"。

### 2. 隐含前提（作者觉得"显然"，阅卷者觉得"莫名其妙"）

作者是构思者，脑子里有完整链条，落笔时只写了其中一段，读者就断了。凡是"显然""自然""不言而喻"的地方，往往就是漏掉的那根箭头。

做法：把你最得意的那句"因为 A 所以 B"单独拎出来，问自己，A 凭什么能推出 B？中间还缺什么？缺的那句，就是你要补的隐含前提。

### 3. 论证负担与排除能力

- 论证负担：观点越绝对、越惊人，作者要负的证明责任越重。"必然""所有人""永远"这类词，能不用就不用。
- 可证伪性：如果一个观点什么反例都能解释成支持它，它其实什么也没说。
- 排除能力：一个有信息量的判断，必须排除掉某些可能。什么都能容纳，通常等于什么都没判断。

## 二、概念界定（论证的起点）

> 一篇文章的高度，一半在开头把核心概念说明白。
> 界定不是把题目换个漂亮说法，而是重新确定它的内涵。

界定之后必须能判断具体行为"算不算"，否则定义是空的。这个判断标准，叫判准。

### 五种界定方法

① 否定法
句式："XX 不是……，而是……""XX 看似……，实际……""XX 不只是……，更是……"
> 例：真正的"坚守"不是咬牙硬撑的意志力，而是把意义锚定在自身之外的那份笃定。

② 语境法
句式："在……时，XX 是……；在……时，XX 是……"
给概念施加条件，既保证在一定条件下的准确，又体现不同条件下的多元。
> 例：面对强权时，沉默是懦弱；面对未知时，沉默是敬畏。

③ 属加种差
句式："作为（属）的一部分，（种差）是它区别于同类的一大特色。"
> 例：作为"人与世界的互动方式"的一种，审美区别于功利的根本，在于它不索取占有，只求观照。

④ 拆字拆词
拆字义、词义生发。适合产生联想，不等于揭示本质，慎用作主论点。
> 例："悲"＝上"非"下"心"，心中被不好的事触动。

⑤ 比喻 / 构成要素 / 功能目的
用喻体揭示本体特征；或列举核心要素；或从"它是为了什么"切入。

### 界定到"判准"的进阶

空定义止于"XX 是 YY"。真正的界定要能落地成判准：
> 适应与迎合都指"人在不适合的环境中融入的方式"。差别在哪？
> 甲选择表达更直接，但心里还会想一想，这是适应；
> 乙选择"别人说的都是对的"，就这样吧，这是迎合。
> 所以判准是：有没有"寻思"这一步，即是否无条件接受环境对自己的影响。

有了判准，你才能说：题中的情况是 X 而不是 Y，因为……

## 三、偷换概念（概念重构）

题目常给一个被写烂的概念（爱国、母爱、青春）。"偷换概念"不是贬义，而是重构，把旧词翻出新意。三种方法：

### ① 泛化（由点到面、横向扩展）

- 对象泛化：个体→群体。苏轼→文人；清洁工→普通人。
- 核心泛化：现象→本质。找出多个个案的共同规律。
- 条件泛化：特殊→一般。把特殊条件下的法则赋予普遍性。

### ② 神化（把平凡概念升华）

把普通概念放进更宏大的价值体系。
> 学习 → 意志的磨炼 → "修行" → 让灵魂摆脱世俗桎梏 → 对不公与不满的救赎。

### ③ 祛神化（把宏大概念拉回生活）

把宏大叙事抽出一部分，放回具体经验。这是让文章有"人味"、避免空喊口号的关键。
> 初心 → 解出一道难题、坚持练字；
> 爱国 → 国旗升起时心头一热、异乡听见母语时回眸一笑、弯腰捡起一片垃圾。

三种方法的组合，能让一个"老掉牙"的话题立刻有了新的可写空间。

## 四、归因法（解决"因为→所以"的那根箭头）

归因＝解决"条件→结论"这个箭头，仅此而已。为什么 A 能推出 B？

### ① 三段论【强制、审判】

大前提（公认）＋小前提（具体情况）＋结论（必然）。
> 所有人都会死；苏格拉底是人；所以苏格拉底会死。

大前提必须是公认的，不能是"我认为……"，否则就是瞎说。

### ② 线性归因【连贯、顺畅】

A→B→C→D，用于解释一个结果如何生成。每一步都必须是高概率发生的，否则就是滑坡谬误。
- 反例：书读不好→考不上好大学→找不到好工作→人生完蛋。
- Tips：①少用"必然"，承认可能性；②链条不要超过 3 个。

### ③ 多点合一【气势、规律】

一个例子有偶然性，找几个不同领域的案例，归纳共同结构。
> 曹雪芹批阅十载（文学）、达尔文观察物种多年（生物）、工匠磨刀半载（技术），领域各异，却殊途同归：专注是跨越平凡的阶梯。

不是罗列，是发现共性，一定要加一句"尽管领域各异，但他们……"。

### ④ 类比【通俗、感性】

A≈B，故 A 的特征 B 可能也有。结构必须一致，拿"猫"类比"石头"很诡异。适合文章太干、太理性时。

### ⑤ 溯源【深刻、寻根】

从结果回推动因，追问"本质"。
> 熬夜 → 不是不自律，而是对"时间自主权"的补偿。

不要停在表面原因，可以结合"神化/祛神化"展开。

## 五、推演法（思想实验，让观点不证自明）

用"时间""空间""如果"做一场推演，使你的观点不证自明、对方的观点不攻自破。四个维度：

### ① 时间轴推演

- 正向（多米诺）：短→中→长期。效率至上→短视频变多→读长文没耐心→思考力退化。
- 反向归谬（极限测试）：假设该观点正确，一路推到底，看它导致多坏的后果。
  > 唯结果论→过程被忽视→规则底线都不重要→退化为弱肉强食→人人自危。

### ② 圈层推演（以小见大）

个人→集体→社会→国家→人类。
> 老人不会用手机→银发族被社会抛下→"科技向善"与人文关怀的时代盲区。

### ③ 变量推演（抽掉核心条件）

直接说"善良有什么好"很抽象；抽掉它，重要性自现。
> 若抽离共情→契约与算计→失去人文关怀→机器与异化。

### ④ 学科推演

借其他学科的结构。
> 生物学：生态系统单一→稳定性弱；→ 社会：成功定义单一→文化脆弱、不再创新。

说理仍是主体，推演能写 100 字就不错了，别喧宾夺主。

## 六、反复法（把观点颠来倒去讲清楚）

不是简单重复，而是有层次的反复。

### ① 单纯反复（围绕一个观点换角度追问）

论点：生命的价值取决于韧性。
> 人生从不是一帆风顺。倘若顺水行舟，船速水速别无二致，个人的光芒如何体现？（假设＋推演）正是逆水行船时，有的帆鼓得足，有的桅杆不堪一击（对比）……由此可见，正是航行中的风浪，才让我们……

抛开素材，论证一样明晰。还可以继续追问"韧性如何在风霜中体现""为何有美感"。

### ② 强制反复（立一个论，再破掉它）

把一个观点当"一派胡言"来攻击，往往会逼出下一个更准的论点。
> "风霜"与"美好"之间那座桥的支柱，从来不是"韧性"，韧性只是桥面。支柱的名字，叫作"行动"。

这就是"自我反驳"的雏形，也是修正法的入口。

## 七、辨析法（真正的思辨，是告诉别人灰何时为黑、何时为白）

> 最廉价的思辨是告诉别人黑与白不同；
> 真正的思辨，是告诉别人，灰何时为黑，何时为白。

### ① 先找相同（找不同之前提）

你为什么要辨析？是因为二者长得很像、难以区分。
- 适合辨析：创新 VS 求异、适应 VS 迎合、责任 VS 压力、共情 VS 认同。
- 不适合：理性 VS 感性（本来就没交集，硬辨是假辨析）。

### ② 找"最小差异"（＝判准）

只有这个条件一改变，才会让 A 变成 B？这个条件就是判准。
> 适应与迎合的判准：有没有"寻思"这一步，是否无条件接受环境的影响。

### ③ 用判准去判

告诉阅卷者：题中的情况是 X 而不是 Y，因为……

两个 bug：
- 判准不是论点。拿到判准后要去"判"，别转移话题讨论判准本身。
- 不要给价值判断（除非问题非黑即白）。伪辨析的经典格式：A 好、B 坏 → 举 C 证 A 好、举 D 证 B 坏 → A 好、B 坏。这只是把结论重新说了一遍。

## 八、反驳与修正（一类文的分水岭）

好文章不是没有漏洞，而是作者自己先把漏洞找出来补上。

- 自我反驳：把自己的观点暂时当成一派胡言，主动攻击它。
- 反例检验：主动寻找不符合自己观点的情况，看遗漏了什么条件。
- 让步法：承认对方在特定条件下成立，然后划定其边界。
- 限定法：加主体、范围、时间、条件，把过强命题修正为能成立的命题。
- 观点降级：证明不了"必然"，就降为"倾向""往往""更可能"。
- 观点重建：反驳的终点不是消灭观点，而是得到一个更坚固的新版本。
- 钢人化：先把反方改成它最合理、最难打的版本，再回应（对比"稻草人"，故意把反方说蠢）。

修正法流程：提出观点 → 攻击观点 → 发现漏洞 → 加入条件/变量 → 形成更准确的新观点。

> 议论文的高级感，不在于"我对你错"，而在于"我如何修正我最初的粗糙"。

## 九、方法论（回答"怎么办"）

方法不能只是"保持清醒、积极行动"，必须形成现实动作。逐项自查：

| 要素 | 要问的问题 |
|---|---|
| **主体** | 究竟谁该行动？个人 / 学校 / 平台 / 社会 / 国家 |
| **动作** | 能否转化成真实可执行的行为？（"制定安排表"是动作，"行动"不是） |
| **机制** | 这个动作为什么能缓解前文分析的问题？ |
| **成本** | 代价是什么？完全没有代价的方案多半是口号 |
| **承担者** | 获益者与成本承担者是不是同一批人？ |
| **可执行性** | 主体是否真的拥有相应资源与权力？ |
| **反馈** | 实施后能否根据结果修正？ |

两个常用概念：
- 工具理性 / 价值理性：既看手段是否高效，也看目标本身是否值得追求。
- 结构与能动性：分清"时代/结构造成的限制"与"个人仍能改变的空间"。（见 `01` 困境论）

## 十、常见谬误清单（批改时对照）

| 谬误 | 表现 |
|---|---|
| **滑坡谬误** | A→B→C→D，每一步都靠语感滑过去 |
| **稻草人** | 把反方说成一个很蠢的版本再打 |
| **幸存者偏差** | 只看成功案例，忽略大量失败样本 |
| **相关当因果** | 两件事同时出现，就断定一个造成另一个 |
| **诉诸权威** | "名人说过"只能证明"他这样认为"，名气不代替论证 |
| **诉诸结果** | 观点产生好后果 ≠ 它是真的 |
| **样本不足** | 几个案例推出普遍规律 |
| **层级错误** | 个人经验直接推社会规律 |
| **自然主义谬误** | "自然/传统/普遍存在"就当作"正当" |
| **休谟问题** | 从"实际上是什么"无条件推出"应该是什么" |

## 十一、论证自检清单（写完后走一遍）

- [ ] 每个分论点，都能指出它凭什么成立（不是"我觉得"）？
- [ ] 每处"因为→所以"，中间那根箭头都补出来了吗？
- [ ] 有没有自己先把最可能失败的地方攻击一遍？
- [ ] 观点里有没有过强的"必然/所有/永远"，需要降级或限定？
- [ ] 素材和结论之间，是我铺的路，还是靠"由此可见"硬跳？
- [ ] 有没有一处真正的辨析（灰何时为黑、何时为白），而不是"A 好 B 坏"？
- [ ] "怎么办"那段，主体、动作、成本落地了吗？

> 记住书稿里那句：你以为 55 分比 48 分只差几个高级词，其实差的，是你觉得"显然"的那根箭头，别人替你说清楚了。
