# 记叙文、小说与散文

> 本文件供 Skill 评阅**非议论文**文体时使用。
> 分工：标准议论文用 `03` 的尺子；散文式议论、故事新编、第二人称等"伪议论文"用 `06`；**标准记叙文、小说、散文用本文件**。
>
> 核心提醒：**拿错尺子，比不量更糟。** 记叙文不要求"补箭头"，散文不要求"论证严密"。

本文件供 Skill 在批改（M5）、整本批改（M6）遇到记叙文 / 小说 / 散文时调用。

## 一、记叙文与小说

### 1. 叙事：先把故事讲清楚

- 叙事结构是否**完整**：起因、发展、结果（或相应的叙事闭环）是否齐备。
- 是否把一个故事**讲清楚**了：读者能不能跟上时间、人物、因果。
- 这是**第一判准**。故事讲不清楚，后面都免谈。

### 2. 语言：先分档，再看侧重点

先判断语言的**档位**，不同档位看不同的东西：

| 档位 | 侧重看什么 |
|---|---|
| **华丽** | **流畅度**：长难句是否过多、是否拗口、用词是否生僻、有没有"假文言"（生造的文言腔）。华丽不是错，**堆砌与不顺**才是错。 |
| **朴实** | **真情实感**：有没有真实的体验与情感；同时看有没有**低幼化**、有没有**非必要的**口语化表达。注意：不是所有口语化都不好，**必要的**口语（贴合人物、场景、语气）反而是优点。 |
| **适中** | 两边兼顾，做一个平衡的评价。 |

### 3. 结构：叙事结构是否清晰

- 时间线、场景转换、伏笔与照应是否清楚。
- **不接受意识流类的叙事**：意识流、碎片拼贴式的写法，在考场上视为结构不清，不因"有风格"而加分。

### 4. 立意：同议论文的立意标准，但判据不同

- 立意是否切题、是否有自己的发现（标准同 `03`）。
- 但**只要叙事内容能够证明立意即可**：不要求显式论证、不要求"补箭头"。**故事本身就是论证方式。**

### 5. 特殊情况

- 偏题、擦边：**与议论文处理方式相同**（见 `03` §零·5 扣题闸门），该封顶就封顶。
- 贴标签、文体不清、整体方向：见 `03` 的对应条目。

## 二、散文

### 0. 一句话判准：形散而神不散

**这是最重要的判准。**
- **形散**：题材、笔触、时空可以自由跳转；
- **神不散**：全文必须有一条贯穿的**主旨 / 情思**。
- 形散了、神也散了（读完了不知道你要说什么）→ 判**结构不清**。

### 1. 语言：同记叙文与小说的分档法

见上文"语言三档"。华丽看流畅，朴实看真情与是否低幼 / 非必要口语，适中做平衡。

### 2. 论证与逻辑：要求不高

- 散文**允许逻辑链存在瑕疵**，只要不太离谱，不影响最终得分。不要拿议论文的"箭头"去卡散文。
- 合格的底线：文中要**展示出与思考、思维链相关的内容**（有联想、有体悟、有理性的推进）。
- **不合格的样子**：通篇"我觉得""我认为"，没有任何论证、佐证、个人体验或感受，仅泛泛而谈、不落实处。
- 即：不要求"证得严密"，但要求"确有所感、确有所想"。

### 3. 立意：认真剖析，但不过度解读

- 同议论文的立意标准（切题、有发现）。
- 但**不要过度解读**：作者可能只是随手一景，不要硬挖出深刻寓意。
- 只要内容能够证明立意即可。

### 4. 特殊情况

- 偏题、擦边：与议论文处理方式相同。

## 三、与议论文尺子的对照（防拿错尺子）

| 看什么 | 议论文 | 记叙文 / 小说 | 散文 |
|---|---|---|---|
| 论证 | 必须显式、箭头补齐 | 不要 | 允许瑕疵，不卡箭头 |
| 叙事 | 次要 | **第一判准** | 可散，但要有"神" |
| 语言 | 准确、说人话 | 分档看 | 分档看 |
| 立意 | 靠论证证明 | 靠叙事证明 | 靠内容证明 |
| 结构 | 逻辑推进 | 叙事清晰（拒绝意识流） | 形散神不散 |

> 一句话：**给记叙文挑"箭头没补齐"、给散文挑"论证不严密"，都是拿错尺子。**
