# 评价平衡性

> 改作文最怕的不是"看不出问题"，而是"盯着一处，压死全篇"。
> 有人被华丽辞藻骗过，有人被一个错别字带偏，有人拿议论文的尺子量散文，
> 本文件给出多维度、有权重、有依据的平衡评价方法。

本文件是 `03-批改与评分.md` 的平衡性补充，执行 M5 批改 / M6 整本批改 时按需调用。

---

## 一、六条核心原则

1. 多维度覆盖：不能仅凭某一维度的表现给出整体结论。
2. 权重动态适配：不同维度权重随文体、写作目的、评价场景调整，调整依据必须说明，不能凭感觉分配。
3. 证据优先于印象：每条结论都要能在原文找到具体语句作依据，避免"感觉""大概"。
4. 优点与不足并重：不"一好百好"，也不"一坏百坏"。
5. 分层反馈：整体印象 → 逐维度展开 → 具体建议。
6. 尊重写作者意图：立足于作者想表达的主题，而不是用评价者的偏好去替代作者的选择。
7. 单项不兜底：任何单一维度的优秀（文采、创意、结构工整），都不能替整体兜底。议论文有两条底线，扣题与论证；两者之一不达标，语言和创意再亮，也封顶在二类下。

> 第 6 条对本 Skill 尤其重要：批改是评"他写得怎么样"，不是评"我会怎么写"。
> 学生选了一个你不喜欢的立意，只要它扣题、能自洽，就要按他的立意去评。

## 二、六个评价维度（平衡检查用）

> 这六个维度用于防止遗漏与失衡；正式打分仍用新高考三项（内容/表达/发展，见 `03`）。

| 维度 | 考察要点 | 常见问题 |
|---|---|---|
| **立意与主题** | 审题是否准确、主题是否明确、思想是否有深度/新意 | 偏题、立意肤浅、套路化 |
| **结构与逻辑** | 框架是否清晰、衔接是否自然、论证是否严密 | 结构混乱、详略不当、论点论据脱节 |
| **语言与表达** | 用词准确、句子通顺、修辞恰当、风格统一 | 病句、堆砌辞藻、风格前后不一 |
| **内容与素材** | 素材真实/典型/新颖，论据充分，细节生动 | 素材陈旧、论据空洞、缺细节 |
| **文体规范** | 是否符合所要求文体、格式是否合规 | 文体混杂、格式缺失 |
| **个性与创新** | 是否有独立思考、个人风格、真情实感 | 千篇一律、机械套模板 |

与新高考三项的映射：立意/内容/个性 → 内容与发展；结构/语言/文体 → 表达。
用法：打分后，用六维度回扫一遍，有没有哪个维度被忽略，或哪个维度被过度放大？

## 三、权重动态适配（议论文默认）

不同文体、不同场景，权重不同。调整时必须在评语里说明依据。

| 文体 / 场景 | 权重最高 | 权重次之 | 可放宽 |
|---|---|---|---|
| **高考议论文（本 Skill 默认）** | 立意、结构与逻辑（论证） | 语言、内容 | 辞藻、格式套路 |
| 抒情记叙文 | 情感真挚、细节描写 | 语言、结构 | 论证严密 |
| 说明文 / 应用文 | 文体规范、内容准确 | 结构、语言 | 立意深度 |
| 竞赛 / 自由创作 | 个性与创新 | 立意、语言 | 格式套路 |

一句话：议论文里，逻辑与论证的权重高于语言辞藻。这不是说语言不重要，而是说"文字优美不能替代论证严密"。

但要注意分寸：逻辑优先不等于只谈逻辑。立意、语言、结构、亮点的权重仍然在，别把批改变成逻辑审讯。权重是"排序"，不是"只留一项"。

## 四、六种典型失衡场景及应对（批改必查）

### 场景 1：文采出众但逻辑松散（使用者高频）

- 失衡：被优美词句吸引，忽视论证漏洞。
- 应对：语言与逻辑分开评价，明确写出，"文字优美不能替代论证严密"。
- 落地：见 `04` 第二·五节"修辞不能替代论证"。

### 场景 2：立意深刻但语言稚嫩

- 失衡：因语言问题给出过低评价。
- 应对：语言问题定性为可通过练习提升的技能性问题，与立意的思想性优势分开评价。
- 落地：不要因为几个病句，就把一篇思辨深刻的文章压到二类。

### 场景 3：套路化结构工整但内容空洞

- 失衡：因结构"标准"（三段式、总分总）而给高分。
- 应对：区分"结构完整"与"内容充实"是两个维度；套路化结构可能是"安全但缺乏个性"。
- 落地：这正是本 Skill 说的"二类切入分（45–48）"，结构完整只能保底，认识不向前移动就上不了一类。

### 场景 4：个别错别字 / 病句被过度放大

- 失衡：因语言细节瑕疵全盘否定文章。
- 应对：把语言细节定性为局部技术性问题，与整体质量分开陈述，避免以偏概全。
- 落地：错别字按 `03` 的规则扣分（3 个以上每个 -1，上限 -5），但不要用它否定全文。

### 场景 5：不同文体 / 学段标准混用

- 失衡：用议论文的逻辑标准要求散文，或用成人标准要求低学段。
- 应对：评价前先确认或推断文体与预期读者、学段，并说明所依据的参照标准。
- 落地：本 Skill 只评议论文（含任务驱动、材料作文）；遇到记叙文/散文走 `03` 情况 B。

### 场景 6：创意突出但偏离题意（本 Skill 高危）

- 失衡：被"去套路化""有个性""敢下判断"吸引，给出过高评价，忽视中心已偏离材料核心。
- 应对：切合题意是内容项的第一要素。创意属于发展等级，发展等级不能救偏题。先判扣题档位，再谈创意加分。
- 一句话：反套路不是通行证，扣题才是。
- 落地：见 `03` §零·5"扣题闸门"与 §六·12。

### 场景 7：单项亮眼，但"扣题 / 论证"不达标

- 失衡：语言优秀、创意突出，就顺手抬进二类上甚至一类，忘了文章其实"不太合题"或"通篇是断言"。
- 应对：先过两条硬门槛（见 `03` §一）：① 扣题封顶（基本切合 ≤51 / 擦边 ≤48 / 偏题 ≤45）；② 论证门槛（论证薄弱或通篇断言 → ≤47）。再按维度定档，**取较低者**。
- 一句话：**单项优秀不替整体兜底。语言优秀 + 不合题 + 无论证 = 平庸。**
- 落地：见 `03` §一"两条硬门槛"。

## 五、反馈表达规范

- 避免绝对化：不用"完美""一无是处""毫无问题"，改用具体、有分寸的描述。
- 具体指出问题：引原文语句，说明问题及原因，不笼统说"语言不够好""逻辑有问题"。
- 给可执行建议：每条批评尽量配改进方向或示例（见 `03` §四·7）。
- 鼓励与批评平衡：再差的文章也找一个真实亮点；再好的文章也指出仍可提升处。
- 抓大放小：一次只挑最关键的 1–2 个问题，不逐句挑病。逻辑审查尤其别死磕，只说最该改的那一处。
- 委婉但不失客观：照顾学生感受，但不回避真问题、不夸大优点。

## 六、特殊情境

### 1. 用户只要单一维度
用户说"只看语言""只评立意"→ 尊重要求，只详评该维度，末尾可轻提一句"如需更全面，可补充其他维度"，不主动越界长篇评价其他维度。

### 2. 面向不同学段
小学生更看重内容真实与语言通顺；中学生可提高对逻辑与立意的要求。不用统一尺度苛责低学段。

### 3. 应试作文 vs 自由创作
应试作文受评分标准与题目约束；自由创作应给更大个性空间。评价时说明所参照的标准类型。

### 4. 用户对评价有争议 / 要求重评
保持开放：重新审视证据是否充分、权重是否合理，而不是简单坚持原结论，也不无条件迎合用户期待改变客观结论。

> 对应到本 Skill：用户说"我觉得不止 44 分"时，重走一遍六维度 + 权重，而不是嘴上安慰或硬扛。

## 七、平衡自检清单（打分前走一遍）

- [ ] 六个维度都扫过了吗？有没有哪个被完全忽略？
- [ ] 我给的权重，符合这篇的文体与场景吗？依据说清楚了吗？
- [ ] 每条结论都有原文依据吗？还是凭"感觉"？
- [ ] 我是不是被某一处（文采 / 错别字 / 一个金句）带偏了？
- [ ] 有没有拿单项优秀（文采 / 创意）替整体兜底？扣题与论证这两条底线过了吗？
- [ ] 亮点和问题都写了吗？有没有"一好百好 / 一坏百坏"？
- [ ] 我是按作者想表达的主题在评，还是按我自己的偏好？
- [ ] 建议具体可执行吗？

> 核心方法论：多维度、有依据、讲权重、给建议。
