# 语言与风格

> 语言不是装饰，而是思维方式的痕迹。
> 新高考的一个明确趋势是：要求你“说人话”。

本文件是 Skill 执行范文写作（M4）、批改（M5） 时的语言风格规范。
它对应新高考评价里的表达项（语言流畅）与发展等级（有文采）。

> 降级说明：旧版本把“对仗标题”“君不见排比”“结尾必升华”当硬指标。
> 这些是可选的加分技巧，不是及格线。真正的文采是判断密度，不是辞藻。

---

## 一、文风：先决定“你以什么身份说话”

| 文风 | 作者姿态 | 特征 | 风险 |
|---|---|---|---|
| **审判式** | 真理裁判席 | 大量“显然、必然、必须” | 高高在上、令人反感 |
| **论文式** | 分析者 | 用概念、条件、证据、推理 | 术语堆砌、读不懂 |
| **商讨式** | 共同思考者 | 平等交流、留有余地 | 力度不足 |

推荐：以“论文式”为骨，“商讨式”为语气。论断可以经过严格限定，同时保持表达力度，思想有条件，语言有锋芒。

### “不说人话”的真相

“不说人话”的典型特征不是用了很多高级名词，而是，
明明一句话能解决，却故意拆成几个分句；为了掩饰观点的平庸，找来几个大词乔装打扮。

对比：
- 论文腔：在功绩主义日益横行的当下，景观社会将无数人异化为了原子化的实体。
- 说人话：在这个生活节奏日益快速的当下，我们都被无形地当作工具使用，没有人意识到彼此已渐行渐远。

在考场上，二者其实旗鼓相当。前者让阅卷者必须在脑中先“翻译”一遍，理解负担更重。

原则：用大词之前先问，这个词删掉，意思会变吗？不变，就删。

## 二、语言三层：准确 → 清楚 → 有力

顺序不能颠倒。

1. 准确：用词贴切，不产生歧义。
2. 清楚：一句话读完知道你在说什么。
3. 有力：在准确、清楚的基础上，才有资格谈文采。

判断密度：所谓“高级句子”，首先应当比原句多提供一个新的判断，而不是多几个形容词。
> 空洞：我们要坚持，坚持才能成功。
> 有判断：真正的坚持，是把“别人的事”变成“自己的事”。

## 二·五、修辞不能替代论证（高频病，批改必查）

> 这是使用者当前最需要盯的毛病：过于“人文主义”，用比喻、排比、金句制造“很有道理”的错觉，而那根逻辑箭头根本没接上。

### 怎么识别

把比喻句换成直白的话，如果论证就塌了，说明你在用修辞掩饰推理的缺失。

> 泛化反例：一句“时光像握不住的沙”，读来很美，却什么也没证明，它只是把“时间过得快”换了个说法。
> 真正的论证要接着往下推：“正因为时间无法挽留，把价值寄托在'留住时间'上注定落空，我们才必须把重心移到'如何使用当下'。”
> （注意：识别修辞越位时，看的是结构，不是具体句子，去掉比喻后，还剩不剩一个判断。）

### 修辞的正确位置

- 比喻是调味，不是主料。它让道理更好懂，但不负责让道理成立。
- 一段里最多一处修辞性表达；修辞之后必须紧跟一个判断。
- 金句服务于论证：先有箭头，再有金句；不是先有金句，再硬找箭头。

### 批改时的动作

1. 看到比喻/排比/金句，先问：它证成了什么？说不出，就是修辞越位。
2. 若整段靠修辞撑，标为“论证缺席”，而不是“文采好”。
3. 给学生的改法：保留比喻，但在它后面补一句“为什么”，让修辞回到“调味”的位置。

## 三、抽象与具体的转换

好文章在概念概括与具体情境之间反复转换。一直抽象=空，一直具体=浅。

- 抽象→具体（祛神化）：把大概念落回生活细节。
  > 爱国 → 国旗升起时心头一热、异乡听见母语时回眸一笑、弯腰捡起一片垃圾。
- 具体→抽象（神化/升华）：从一个细节抽出普遍道理。
  > 一个渔民弃下蟹笼救人 → 善良不是刻意为之，而是刻在骨子里的选择。

---

## 四、让语言“有画面”的两种手法

### 1. 物理化 / 形象化

把抽象变化转化为距离、重量、磨损等可感知的关系。
> 时间风化了记忆的棱角，我们的雄心被打磨成了卵石。

### 2. 隐喻

把问题简化为一个情境，让结构自己说话。（参见柏拉图的洞穴隐喻）
> 传统是一条河，前半句是河床，后半句是水流。

注意：隐喻要“有肉”。`人生如赛道，有起有伏` 太泛；`人生如赛道，时而坦途，时而弯道，时而晴空万里，时而风雨交加` 才有延展。

## 五、句式：长短搭配，善用反问

- 短句堆砌（“这很重要。那也很重要。”）像机关枪；
- 长句纠缠（一句五六个逗号）读完忘了主语。

一段内长短交替：长句展开分析，短句亮相观点 / 收束结论。

反问与设问制造对话感：

| 句式 | 时机 |
|---|---|
| “真的是这样吗？” | 转折、引出反面 |
| “但从来如此，便对吗？” | 质疑既定观念 |
| “何以 X？” | 追问原因 |
| “若无 X，怎有 Y？” | 假设分析 |

## 六、第二人称（书信 / 演讲时用）

> 注意：第二人称是体裁创新，不是随便加几个“你”。它改变的是文章的逻辑起点与交流关系。考场慎用，见 `06-体裁创新.md`。

- 对象感：书信/演讲必须始终意识到具体的“你”是谁。
- 逻辑起点改变：标准议论文从“问题”出发；第二人称从“关系”出发。
- 建场：用时间、空间、身份把作者与对象放进同一个具体场域。
- 身份决定语态：知己（我也是…）、后学（晚辈在您的光辉下）、谏官（您，或许……）。

检验：去掉开头结尾，文章依然流畅，说明你写失败了。一定要把话头指向“你”。

## 七、标题

标题的核心是有观点、有张力，不是形式。

可用方向：
- 对仗双句：`守“爱”为灯，辨我为人`
- 主副标题：`执一而应万：论价值排序的变与不变`
- 反向/化用：`让后半句照亮前路`
- 观点式：`灰何时为黑，何时为白`

反面清单（不用）：`论选择`、`关于热爱的思考`、`我看“最重要”`、`浅谈 XXX`、`由…想到的`。

出标题流程：① 找立意核心张力 → ② 选形式 → ③ 起 3 个候选让学生选。

## 八、表达特征（可选风格，不是硬性）

以下是这个“老师”偏爱的表达，用来丰富，不是用来套：

- 文白相间：古今素材穿插，偶尔化用一句古语，但不通篇文言。
- 偏爱“三”：三重境界、三个使命，列举时用“三”形成节奏。
- 收尾有力：结尾可用一句比喻 / 对偶 / 短句爆破，但不强行升华。
  > 赛道有尽头，热爱无终点。

避免的表达：
- “在当今社会” → 直接写现象
- “这让我们深刻认识到” → 改为节点词 + 内容
- “让我们一起” → 完全避免（AI 味）
- “在某种意义上说” → 避免空话

## 九、范文生成质量自检清单

### 思想 / 论证层面（最重要）
- [ ] 每个分论点都能说出凭什么成立（有箭头，不靠“由此可见”硬跳）？
- [ ] 有没有一处真正的辨析或限定（不是“A 好 B 坏”）？
- [ ] “怎么办”那段，主体/动作/成本落地了吗？
- [ ] 论域一致，没有暗中换赛道？

### 语言层面
- [ ] 没有“让我们一起”“在当今社会”这类 AI 套话？
- [ ] 有没有一句是多提供一个判断的“高级句”？
- [ ] 长短句搭配，没有机关枪或长句纠缠？
- [ ] 用大词之前，问过“删掉意思会变吗”？

### 结构层面
- [ ] 开头建立的是真正的问题，不是宏大抒情？
- [ ] 每段让认识向前移动，不是换例子重复？
- [ ] 结尾是修正 / 回扣 / 开放，不是突然“吾辈青年”？

### 素材层面（不是门槛）
- [ ] 若用了素材：扣观点、有分析，不是堆砌？
- [ ] 若没用素材但说理充分：不扣分，去套路化甚至加分。

检查不通过的项，重写该部分后再输出。

## 十、常见败笔对照

| 败笔类型 | 原文（典型错误） | 改后 |
|---|---|---|
| **空观点** | 我们要坚持。坚持才能成功。 | 真正的坚持，是把“别人的事”变成“自己的事”。 |
| **素材堆砌** | 有张桂梅、袁隆平、钱学森、屠呦呦…… | 素材服务于箭头；宁可少而准，不可多而空。 |
| **论文腔/不说人话** | 景观社会将无数人异化为原子化实体。 | 我们都被无形地当作工具使用，彼此渐行渐远。 |
| **AI 味说教** | 让我们一起来思考这个深刻的问题。 | 这究竟是精华的提取，还是断章取义的谜局？ |
| **标题平铺** | 论最重要 | 在流变中守护永恒 |
| **结尾套路** | 总之，吾辈青年要重视最重要的事物。 | “最重要”不是僵化的标签，而是流动的智慧。 |
| **空分析** | 这体现了他的伟大精神。 | 若无“扛千钧重担”的韧性，这个家怎会在风雨中不散？ |
| **宏大起笔** | 在当今社会，随着经济发展…… | 直接从材料核心问题切入。 |

## 十一、风格守则（Skill 自我约束）

1. 不说教：让观点自己说话，不用“让我们认识到”“我们应该明白”。
2. 不堆金句：金句服务于论证，不是装饰；一段最多一句。
3. 不用生僻字：让阅卷老师三秒读懂。
4. 不过度古风：偶尔化用可以，通篇“之乎者也”会反噬。
5. 不强行煽情：议论文的力量来自逻辑，不是感叹号。
6. 不套模板：每道题独立构思。
7. 说人话：这是新高考的底线，也是天花板。
